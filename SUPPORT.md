# Support

Use [GitHub Issues](https://github.com/QuinntyneBrown/hewn/issues) for
reproducible bugs, feature requests and documentation problems.

## Bugs

Please include:

- a short summary of the problem;
- reproduction steps, including the direction you submitted if relevant;
- expected behavior;
- actual behavior;
- the stage, run ID or page involved;
- logs, screenshots or Playwright traces, with secrets removed;
- whether the worker ran locally or in the cloud;
- operating system, browser, .NET SDK, Node.js, npm and Docker versions.

## Feature Requests

Please include:

- the problem the feature solves;
- the pipeline stage or Mission Control page it affects;
- any design constraints or examples;
- whether it changes the API, SignalR events, the worker protocol, the database
  schema or the skills.

## Questions

For setup or usage questions, include the command you ran and the output you
received.

## Security

Do not use public issues for vulnerabilities. Follow the process in
[SECURITY.md](SECURITY.md).
