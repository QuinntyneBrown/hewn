Foundation

Responsive

Mobile first, five breakpoints, one column on phones and a sidebar from 992px. No page scrolls sideways at any width from 320 to 2560px.

WCAG 2.2 AA

Overview

  • Base styles are the phone. Each breakpoint adds: columns, rails, the sidebar. There are no max-width queries.
  • Breakpoints are Layout's five: sm 36rem (576px), md 48rem (768px), lg 62rem (992px), xl 75rem (1200px), 2xl 96rem (1536px), matching L2-046's XS/S/M/L/XL bands.
  • Layout tokens (--layout-columns, --layout-gutter, --layout-margin) step up at md and lg, so most components need no query at all.
  • lg is the big change: the sidebar appears, the top bar goes, row lists become tables, rails appear beside content and touch-sized targets return to control heights.

Touch and pointer

  • Below lg, every control is ≥ 44×44px: small and medium control heights are 44px, tabs are at least 44px wide, and nav links, icon actions, menu items, state links and the top bar's menu button use --target-comfortable.
  • From lg, controls use their control height (32–40px), which still clears WCAG 2.5.8's 24px minimum; small targets in rows keep ≥ 8px between them.
  • (hover: none) reveals anything that is hover-only on desktop (row actions, the tile Open link); nothing is reachable by hover alone.
  • (pointer: coarse) is not used to grow targets; they are already large enough below lg.
  • Fixed bottom parts (bottom sheet footer, toast region) add env(safe-area-inset-bottom).
  • Dashboard layout editing (drag to move, handle to resize) is desktop only, ≥ 992px; below that tiles stack and Edit is hidden.

Usage

  • Write the phone layout first, then add @media (min-width: …) blocks in ascending order at the five values only.
  • Prefer intrinsic layouts (auto-fill grids, flex-wrap, minmax(0, 1fr)) to breakpoints.
  • Hide with .sm-only / .lg-only utilities only when the content exists elsewhere at that size; never hide information on phones.
  • Long strings (paths, SHAs, URLs) truncate or wrap with overflow-wrap: anywhere; they never push the page wide.

Accessibility

  • 1.4.10 Reflow: 320px with no two-dimensional scroll, except tables and the log inside their own scrolling wrapper, which has a focusable region and a label.
  • 1.3.4 Orientation: no orientation lock.
  • 2.5.8 Target size: ≥ 24px everywhere, ≥ 44px for main targets below lg.
  • 2.4.11 Focus not obscured: the sticky top bar never covers the focused element (scroll-padding-top), and the bottom sheet's sticky footer does not cover the field being edited.
  • 1.4.4 Resize text: breakpoints are in rem, so at 200% text a 1280px window gets the md layout instead of overflowing.
