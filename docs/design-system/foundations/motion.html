Foundation

Motion

Motion confirms that something happened and shows where it went. Seven durations, four easings, one delay; under reduced motion transitions are instant and loops stop.

Overview

  • Most motion is feedback: a hover tint (120ms), a tab underline sliding (200ms), a dialog rising in (240ms). Nothing moves to decorate.
  • Things arriving use --ease-enter (the prototype's curve: fast out, long settle); things leaving use --ease-exit and are quicker; everything else uses --ease-standard.
  • Loops show live work: the running pipeline segment and log cursor pulse, the spinner turns, skeletons shimmer. All share --duration-pulse (2s) so the screen breathes at one rate.
  • The mocks' raw timings (2s pulse, 1.4s shimmer, 1.2s cursor) and raw easings (linear, ease-in-out) were replaced by these tokens.

Durations

Press a button to replay the move at that duration. With reduced motion on, every dot jumps: that is the intended behaviour.

Distances are the same; only the duration changes.
TokenValueUse
--duration-instantState flips with no transition.
--duration-fastHover and press: colour, background, scale.
--duration-baseSmall moves: tab underline, chevrons.
--duration-slowDialog and drawer entrance.
--duration-deliberateLarge moves you should notice: toast timer bar reset.
--duration-pulseLooping pulse: running segment, log cursor, skeleton shimmer.
--duration-spinSpinner rotation (the prototype's slow spin).

--duration-deliberate (500ms) is reserved for large moves a person should notice; no shipped component uses it yet.

Easing

Each curve played at --duration-deliberate so the shape is visible; in the product they run at fast to slow.
TokenValueUse
--ease-standardMost transitions.
--ease-enterThings arriving: dialogs, drawers, toasts (the prototype curve).
--ease-exitThings leaving.
--ease-linearLoops: spinner and shimmer.

Choreography

MomentWhat movesDuration · easing
Hover, pressBackground and colour; buttons scale to 98% while active.--duration-fast · --ease-standard
Tab change, chevron, switch thumbUnderline slides; chevron rotates; thumb travels.--duration-base · --ease-standard
Dialog opensBackdrop fades; panel rises 8px and scales from 96% (sm+), or slides up as a sheet (below sm).--duration-slow · --ease-enter
Drawer opensSlides in 24px from its edge while fading in.--duration-slow · --ease-enter
Toast arrives / leavesRises 8px and fades in; leaves by fading and dropping back.--duration-slow · --ease-enter / --duration-base · --ease-exit
Menu opensRises in from the trigger.--duration-fast · --ease-enter
Live workRunning segment and log cursor pulse; spinner turns; skeleton shimmers.--duration-pulse / --duration-spin
  • One thing moves at a time. A dialog and a toast do not both animate in on the same click.
  • Exits are faster than entrances; nothing waits for an exit animation before the next step can be used.
  • Never animate layout properties (width, height, top); animate opacity, transform and translate.
  • Status changes from the event stream do not animate in place; the new status word and icon simply replace the old one, and the live region announces it.

Usage

  • Every transition and animation reads a duration and an easing token. A raw 0.3s ease is drift.
  • Use --duration-instant for state flips that should not animate (selected rows, edit-mode shadow).
  • Loops are for live, ongoing work only and stop when the work does: a Paused segment does not pulse.
  • Tooltips use --delay-tooltip on show only, so moving across a toolbar does not flash a row of tooltips.

Accessibility

  • 2.3.3 Animation from interactions and prefers-reduced-motion: reduce: tokens.css sets fast, base, slow and deliberate to 0.01ms (transitions still fire their end events) and pulse and spin to 0s (loops stop rather than flash). Components need no media queries of their own.
  • With loops stopped, live work is still visible: the spinner keeps its icon and label, the running segment keeps its accent fill, the status word still says Running.
  • 2.2.2 Pause, stop, hide: no loop is decorative and none runs longer than the work it shows; the log's auto-follow can be turned off with Follow log.
  • Nothing flashes more than three times a second (2.3.1); the fastest loop is 2s.
  • Smooth scrolling in the docs is off under reduced motion; the product does not smooth-scroll.
@media (prefers-reduced-motion: reduce) {
  :root {
    --duration-fast: 0.01ms; --duration-base: 0.01ms; --duration-slow: 0.01ms; --duration-deliberate: 0.01ms;
    --duration-pulse: 0s; --duration-spin: 0s;
  }
}
