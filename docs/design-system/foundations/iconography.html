Foundation

Iconography

69 outline icons on a 24-unit grid, drawn with a 2px round stroke in currentColor. Icons support a word; they never replace one, except on labelled icon buttons.

WCAG 2.2 AA
  • Overview

  • Sizes
  • Status icons

Overview

  • Every icon is an inline SVG with viewBox="0 0 24 24", fill: none, stroke: currentColor, stroke-width: 2, round caps and joins (.icon). Lucide-style geometry and names, drawn from the mocks' own set so the product needs no icon font or network.
  • Icons inherit the text colour, so a status icon is the status colour and an icon in a button is the label colour. Never fill an icon or give it its own colour outside the status and callout roles.
  • Decorative icons are aria-hidden="true". An icon that is the only content of a control gets its name from the control's aria-label.
  • One icon means one thing everywhere: loader is always work in progress, x-circle always failed or blocked, pause-circle always paused.

Labelling

  • Decorative (next to a word that says the same): <svg class="icon" aria-hidden="true">. This is the default from the helper.
  • Icon-only control: the button or a carries aria-label with verb and object (Refresh workers, Open navigation, Close menu) and shows a tooltip with the same words.
  • Meaningful on its own (a status icon in a compact cell): role="img" and aria-label (Failed), or a visually hidden word next to it.
  • External links add the external icon after the label and say so in the name if it opens a new tab (Open PR #28 on GitHub).
  • Never use an icon as the only cue for something a person must act on; Blocked has the x-circle and the word.

Usage

  • Use an icon only when it speeds recognition of something repeated: status, navigation, common actions (copy, refresh, external). A one-off action gets a word.
  • Leading icons in buttons are for the primary verbs people scan for (New direction with plus); most buttons have none.
  • Do not rotate, mirror or recolour icons to mean something new; add an icon to the set instead (24-unit grid, 2px stroke, 2px padding, round joins).
  • Spinning is reserved for loader and refresh during reconnects.

Accessibility

  • 1.1.1: every icon is either hidden (decorative) or named (role img or the control's label); the checker fails unnamed icon-only buttons.
  • 1.4.11: status and callout icons use the -icon roles, checked at 3:1 against surface, canvas and their callout fill.
  • 1.4.1: icons add a non-colour cue to status, but the word is the primary cue.
  • 2.5.8: an icon is never the target; the control around it is ≥ 24px (44px below lg for main phone targets).
