Foundation

Typography

Two families, nine sizes and thirteen role shorthands. Body text is 16px, nothing is smaller than 12px, and every size is in rem so it follows the reader's zoom.

Overview

  • Inter for every UI string; JetBrains Mono for anything a person might copy or compare character by character: SHAs, paths, worker ids, tokens, log lines. Both fall back to the system stack, so the mocks work offline with no web fonts.
  • Components set type with one role shorthand (font: var(--text-label)), not four separate properties. A role is weight + size + line height + family.
  • The scale has a floor of 12px. The mocks' 11px --font-size-2xs (bar labels, stage live lines, flags) was removed, and 13px and 15px one-offs in tile titles, file paths and decisions were snapped to 14px and 16px.
  • Sentence case everywhere; no all-caps labels. The sidebar's section labels are an overline role (12px medium), not uppercase text.

Measure and responsive type

  • Prose stops at --layout-measure (65ch) via .max-measure; descriptions under titles stop at 40rem; empty-state text at 28rem. See Layout.
  • Type does not scale with the viewport. The one responsive change is the sign-in headline: --font-size-3xl (36px) below sm, --font-size-4xl (48px) from --layout-breakpoint-sm.
  • The increment video's in-frame headings use clamp(var(--font-size-xs), 1.6vw, var(--font-size-lg)) because they draw a scaled-down app inside a frame; that is the only viewport-relative size.
  • Numbers that change in place (spend, percentages, counts, durations) use font-variant-numeric: tabular-nums (.tabular) so they do not jitter.
  • Titles that might wrap use text-wrap: balance; long ids and paths truncate with an ellipsis (.truncate) and show in full in a tooltip or on the detail page.

Usage

  • One h1 per page (--text-h1), the page or project name. Headings go in order; do not pick a heading level for its size.
  • Body copy is --text-body (16px). Dense rows, tables and callouts are --text-body-sm (14px). Metadata is --text-caption (12px) in --color-fg-subtle.
  • Labels, buttons and status words are --text-label: medium weight carries emphasis, colour does not.
  • Anything copyable or comparable is mono: 5a1fe37, wk-4e18, docs/specs/L2.md, hewn:cancelled.
  • Do not write a raw font-size in pixels. If a size is missing from the scale, the design is wrong or the scale needs a step; ask, then add it to tokens.py.

Accessibility

  • 1.4.4 Resize text: every size is rem, so a 200% browser font size doubles the type; layouts reflow rather than clip.
  • 1.4.12 Text spacing: nothing has a fixed height around text; rows and controls use min-height, so 1.5× line height, 2× paragraph spacing, 0.12em letter spacing and 0.16em word spacing do not clip.
  • Minimum size: 12px for any text, 16px for anything a person reads at length and for input values (so mobile browsers do not zoom on focus).
  • 1.4.3: caption-sized text uses roles that are checked at 4.5:1; there is no reliance on the large-text exemption.
  • Inter's tabular figures and JetBrains Mono's distinct glyphs reduce misreads of money and ids; never fake mono with letter spacing.
