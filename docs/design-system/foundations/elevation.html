Foundation

Elevation

Elevation is surface colour first and shadow second. Four shadow levels, tinted for each theme, and nine named layers so nothing ever writes a raw z-index.

WCAG 2.2 AA

  • Surface hierarchy
  • Focus shadow
  • Z-order

  • Tokens

Overview

  • A thing that floats is lighter (dark) or brighter (light) than what it floats on and casts a shadow. Surface colour does most of the work in dark, where shadows barely show.
  • Four levels: 1 resting tiles, 2 tiles being edited and preview frames, 3 toasts, menus, tooltips and the log's jump pill, 4 dialogs and drawers. Cards and rows have no shadow; a hairline is enough.
  • Shadows are tinted with --shadow-color (slate ink in light, pure dark in dark) and get stronger in dark so they still read on a dark page.
  • Layering uses --z-* tokens only.

Surface hierarchy

Canvas → surface → raised, with sunken for wells. In dark each step up is lighter (slate 950 → 900 → 850); in light the canvas is stone and surfaces are paper, and raised steps slightly back to stone so dialogs separate from the white tiles behind the scrim.

Overlays add the backdrop (--color-bg-backdrop) behind them so the page recedes; the backdrop, not the shadow, separates a dialog from the page.

Focus shadow

--shadow-focus draws the focus ring as two box shadows (offset gap in --color-focus-ring-offset, then the ring) for a part whose outline would be clipped by an overflow: hidden ancestor, such as something focusable inside a dashboard tile body or the video frame. No shipped component needs it yet; everywhere the ring is a real outline, which forced-colours mode keeps, so reach for the shadow only when the outline is genuinely clipped.

Z-order

Nine layers, far enough apart that a component can add 1 inside its own layer. Toasts sit above dialogs, so a failure during a dialog is still seen; tooltips and the skip link are topmost.

Usage

  • Pick the level by what the thing is, not how important it feels: a toast is level 3 wherever it appears.
  • Combine shadow with the inset hairline ring (box-shadow: inset 0 0 0 var(--border-width-hairline) var(--color-border-default), var(--shadow-3)) so the edge stays crisp in both themes.
  • Do not animate shadows; animate opacity and transform. Edit-mode tiles switch from level 1 to 2 instantly.
  • Never write z-index: 9999. If two things in the same layer collide, the later one in the DOM wins; restructure before inventing a layer.
  • --z-popover is reserved for a popover opened from inside a dialog; no current screen uses it.
