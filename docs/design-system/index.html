How to use

  1. Link the two stylesheets, tokens first: <link rel="stylesheet" href="tokens/tokens.css"> then assets/components.css.
  2. Write the markup shown on each component page; the class names and ARIA attributes are the API. Do not restyle a component in page CSS: override its component tokens (--btn-bg, --field-border, …) instead.
  3. Theme with data-theme="light|dark" on <html>; with no attribute the OS preference wins.
  4. Generate platform constants (Angular, Sass, native) from tokens/tokens.json (W3C DTCG format; dark values under $extensions).
  5. Every new colour pairing goes into tokens/contrast-pairs.json and must pass check_contrast.py.

Press t or use the toggle in the sidebar to switch theme; token values and contrast ratios on every page update live.
