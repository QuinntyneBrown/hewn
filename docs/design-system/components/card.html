Card

A card is a bordered surface that groups one object’s content: an increment’s steps, a pull request, a budget. It holds content; it is not itself a control.

WCAG 2.2 AAStatus: stable.card

Overview

Use a card to set one object apart from the page around it when it has more than a line of content: the increment card above the stage log, the pull request card in an increment’s aside. Use a dashboard tile for a panel on the dashboard grid, a Row list or List for many objects of the same kind, and plain sections with a Divider when the content belongs to the page rather than to an object.

  • Static card (.card): a surface with a 1px inset ring and 16px padding. Links and buttons go inside it.
  • Link card (.card--link): the whole card is one <a> to the object (the pull request on GitHub). It has a hover tint and nothing interactive inside it.
  • With header and footer (.card__header, .card__footer): a title bar and an action bar, each separated by a hairline and bleeding to the card edge.
  • Selected (.card--selected or aria-current="true"): the accent tint and accent ring for the chosen card in a set.

Anatomy

  1. Header (optional).card__header: title (.tile__title, h3) and meta, 12 × 16px padding, hairline below.
  2. Container--color-bg-surface, 1px inset ring --color-border-default, --radius-md, padding --space-4.
  3. BodyAny content; inside spacing --space-3 to --space-4.
  4. Footer (optional).card__footer: actions right-aligned, small buttons, hairline above.

Sizes

Cards have one padding (16px) and take the width of their column; content sets the height.

States

Only link cards have pointer states. Hover raises the surface to --color-bg-surface-raised; focus draws the shared ring around the whole card; selected uses the accent tint.

A static card is never hoverable: tinting a non-interactive card on hover promises a click that does nothing.

Responsive behaviour

  • Cards fill their column at every breakpoint; they never set a width. In a set, use .grid--cards (auto-fill, minmax(min(100%, 18rem), 1fr)): one column at 360px, two from about 37rem, three or more in wide content.
  • Below --layout-breakpoint-sm (576px) a card’s cluster rows wrap (the increment card’s tags move under the title); the step labels truncate with an ellipsis and the iteration sub-label is hidden.
  • From --layout-breakpoint-xl (1200px) the pull request card sits in the 24rem aside of .split--aside; below xl it follows the main column.
  • Long titles in a link card wrap; metadata lines (.list__sub) truncate.

Theming

The card reads two component tokens: --card-bg (default --color-bg-surface) and --card-ring (default --color-border-default). Hover sets --card-bg to --color-bg-surface-raised; selected sets --card-bg: --color-accent-subtle and --card-ring: --color-accent.

/* A sunken card for a code sample, without editing .card */
.card.card--sunken { --card-bg: var(--color-bg-surface-sunken); }

In dark the surface steps up from the canvas by lightness rather than shadow, so a card reads as raised without a drop shadow; the ring keeps its edge visible on both.

Accessibility

Role and pattern

No widget role. A static card is a <div>, or a <section> with aria-label when it is a meaningful region. A link card is a single <a href> with block content; it never contains another link or button (no interactive content inside interactive content). Selected cards in a set carry aria-current="true"; if choosing a card is a form choice, use a radio group styled as cards instead.

Keyboard

KeyAction
TabMoves to the link card, or to the links and buttons inside a static card, in DOM order.
EnterFollows a link card.

Focus

A link card shows the shared 2px ring with a 2px offset around the whole card. Static cards are not focusable.

Labelling

A link card’s accessible name is all of its text, so keep it short: title first, then one meta line. Status icons inside carry their own name (Merged, Open) because colour alone does not tell them apart.

Motion

Link card background transitions over --duration-fast; reduced motion zeroes it.

Touch

A link card is the whole target, comfortably larger than 44px tall.

Content

  • Lead with the object’s name (Reconcile a card statement), then one meta line with numbers in tabular figures (#28 · open · +612 −48 · 14 files).
  • Card header titles are nouns in sentence case: Budget, Pull request.
  • Footer actions are verbs (Raise budget); at most two, the stronger last.
