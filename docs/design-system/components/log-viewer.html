Log viewer

The log viewer streams what an agent is doing, line by line, so an Owner can watch a stage run and see exactly why it failed.

WCAG 2.2 AAStatus: stablerole="log"

Overview

Use the log viewer for the worker's output on the pipeline screen: one line per event, newest at the bottom, following new lines while the reader is at the bottom and holding still when they scroll up. It is the only place raw agent output appears. For a human summary of a run use the Timeline; for a short command to copy use the Code block.

  • Live: a run is streaming; a pulsing cursor sits under the last line and the box follows new lines.
  • Finished: the run ended (Paused, Cancelled, Complete or Failed); no cursor, the last line says how it ended.
  • Scrolled up: the reader left the bottom; new lines still arrive but the view stays put and the n new lines — Jump to latest pill appears (L2-033).

Anatomy

  1. Timestamp.log__t: HH:MM:SS in the worker's clock, tabular figures, --color-fg-subtle.
  2. Level.log__lvl: the word info, tool, warn or error, coloured by level; the word carries the meaning.
  3. Text.log__text: verbatim output, wraps anywhere so long paths never scroll sideways.
  4. Cursor.log__cursor: pulsing accent block while the run is live; aria-hidden.
  5. Jump pill.log__jump: appears when scrolled up with new lines below; a real button.

Sizes

The log has one density: 12px mono (--text-log) on a loose line height. Only its height changes, by breakpoint; see Responsive.

  • Follow: while the box is scrolled to the bottom, each new line scrolls it down. Scrolling up by any means (wheel, keys, dragging) stops following; reaching the bottom again, or pressing the pill, resumes it.
  • Jump pill counts new lines since following stopped and updates in place; it disappears on the bottom.
  • Finished removes the cursor and keeps the scroll position; the box never clears on its own.

Responsive behaviour

  • Base (360px): timestamp column 4.5rem, level column 3rem (--space-12), text takes the rest and wraps anywhere (overflow-wrap: anywhere), so a long git command or path never scrolls sideways.
  • From sm (36rem) the timestamp column widens to 5rem.
  • The box is 26rem tall below lg and 28.75rem from lg (--layout-breakpoint-lg), where it sits beside the stage list in .split--pipeline.
  • The jump pill is centred 16px above the bottom edge at every width and never wraps; at 360px its label is 12 new lines — Jump to latest, which fits.

Theming

The box reads --color-bg-log (the canvas tone in light, --palette-slate-950 in dark) so it reads as a sunken console in both themes. Levels read status text tokens, not palette colours, so each keeps 4.5:1 on the log background in both themes. Hovered lines use --color-bg-surface; the dark --color-fg-subtle was lightened to keep timestamps legible there (see drift).

/* A taller log on a dedicated full-screen view */
.log--full .log__box { height: calc(100dvh - var(--layout-topbar-height) - var(--space-16)); }

Accessibility

Role and pattern

The box is role="log" (implicitly aria-live="polite", additions only) with an aria-label naming the stage. There is no APG pattern for logs; see the WAI-ARIA log role. Lines are batched (at most one DOM update per animation frame) so screen readers are not flooded; an Owner who wants silence turns Follow log off (), which also stops live announcements.

Keyboard

KeyAction
TabMoves focus to the log box (it is a scrollable region with tabindex="0"), then to the jump pill when it is shown.
↑ / ↓Scrolls the box by a line. Scrolling up stops following.
Page Up / Page DownScrolls by a box height.
Home / EndJumps to the first or last line; End resumes following.
Enter, SpaceOn the jump pill: scrolls to the latest line, resumes following and moves focus back to the box.

Focus

The box shows the shared focus ring when focused. Pressing the jump pill removes it from the page, so focus moves to the box rather than being lost. New lines never move focus.

Labelling

Name the box after what it logs: Run log, stage 10 Increments. Each line's level is a visible word, so meaning never depends on colour (1.4.1). The cursor is aria-hidden.

Motion

The cursor pulses on --duration-pulse; following scrolls instantly (never smooth-scrolls, which would lag a fast stream). Under reduced motion --duration-pulse is 0s, so the cursor is a still block and still marks the live run.

Touch

The box scrolls with the finger; the jump pill is 32px tall (--control-height-sm) and full-pill wide, comfortably above the 24px minimum, and floats clear of the last line.

Content

  • Lines are verbatim agent output; the UI never rewrites them. What the UI adds (the pill, the waiting state) follows the content rules.
  • Timestamps are 24-hour HH:MM:SS in the worker's time zone, tabular.
  • Pill label: {n} new lines — Jump to latest; singular 1 new line.
  • Waiting copy says what happens next and that nothing is needed: Stage 0 starts as soon as a worker leases it, usually within 2 seconds. Nothing to do here.
  • The final line of a finished run says how it ended: Step finished · checkpoint a8d2e41 · direction Paused.
