Text field

Text fields take one line of input: a project name, a GitHub login, a budget, a worker name, a search term.

Overview

Use a text field for a short, free-form value the person types. It always sits inside a form field that gives it a visible label, a hint and room for an error. Use a Textarea when the text can run to several lines (an idea, a feature), a Select or radio group when the answer comes from a fixed list, and a Switch for an on/off setting.

  • Text: names and free text (Name, Stack, Existing repository).
  • Money prefix (.prefix.prefix--money): budgets. A fixed $ sits inside the field; the value is inputmode="decimal" with two decimals.
  • @ prefix (.prefix): GitHub logins, so people do not type the @ themselves.
  • Mono (.input.mono): machine identifiers that are copied character for character (worker names, repository paths).
  • With unit: a short number with its unit as text after it (3 ideal days).
  • Search (.prefix.prefix--search, type="search"): filters a list in place, like the requirement list on Traceability.
  • Secret with reveal (.suffix): API keys and webhook secrets, masked, with a Show button.

Numbers are typed into type="text" with inputmode, not type="number": number inputs drop the trailing zeros in 400.00, change value on scroll and spin buttons, and announce inconsistently.

Anatomy

  1. Label.field__label, --text-label, --color-fg-default; a <label for>.
  2. Prefix (optional).prefix__sym, --color-fg-subtle, aria-hidden; the input's left padding grows to --space-6.
  3. Value--text-body-sm in --field-fg; tabular figures in money fields.
  4. ContainerHeight --control-height-md, --radius-md, 1px inset ring --field-border on --field-bg; padding --space-3.
  5. Hint or error.field__hint (--text-caption, --color-fg-subtle) or .field__error, linked with aria-describedby.

Sizes

Medium (40px) is the default for every form. Small (32px) is for filters and rails next to small buttons; large (48px) is for a single prominent field such as a confirmation on a phone.

Heights --control-height-sm/md/lg; large also steps the value up to --text-body.

  • Invalid is aria-invalid="true" plus a message: the ring thickens to 2px --field-invalid and the field's error replaces the hint. Colour is never the only signal.
  • Read-only (readonly) is used while a form submits and for Viewers: the value stays focusable, selectable and announced, on --color-bg-subtle. Prefer it to disabled, which removes the value from the tab order, the screen reader's form list and the submission.
  • Disabled is for a control that cannot apply at all in this context; say why next to it.
  • Active has no distinct look: pressing an input focuses it, so it shows the focus ring. Hover darkens the edge to --color-fg-muted.

Responsive behaviour

  • Mobile first, fields fill their column at every breakpoint; the column stops at --layout-form-max (42rem) in .form-col and at the dialog width in dialogs.
  • Below --layout-breakpoint-sm (36rem) every field is one column; from sm, short related fields pair up in .form-grid--2 (Stack and Existing repository).
  • Money fields keep a fixed 10rem (.prefix--money) and unit fields 6rem at every size, so the number never stretches across a desktop column.
  • From --layout-breakpoint-lg (62rem) the Traceability search moves into the 17rem rail; below lg it sits above the requirement strip at full width.
  • Height stays 40px on phones; the label is part of the target, so the tap area is label + field.

Theming

The field reads component tokens set on .field: --field-bg, --field-fg, --field-border, --field-ring and --field-invalid. A theme changes the semantic tokens underneath; a local re-skin overrides the component tokens on a wrapper.

/* Fields on a sunken panel keep their contrast */
.panel--sunken .field { --field-bg: var(--color-bg-surface-raised); }

In dark the field is a step above the canvas (--color-bg-surface), its edge is the lighter --color-border-strong and the invalid ring is the dark-theme red icon colour, all at 3:1 or more.

Accessibility

Role and pattern

Native <input> with a visible <label for>; there is no APG widget pattern for a text box, so follow the W3C forms tutorial on labels and instructions. Search fields are type="search" inside a role="search" region when they filter the whole page.

Keyboard

KeyAction
Tab / Shift + TabMoves into and out of the field.
EnterSubmits the form the field belongs to (single-line fields only).
EscIn type="search" clears the query; inside a dialog it closes the dialog.
Space / Enter on ShowReveals or masks the secret; focus stays on the button.

Focus

Focus replaces the 1px edge with a 2px inset --field-ring, so the ring is never clipped by a scrolling dialog. A focused invalid field currently keeps only the red ring; the fix (an outer focus ring around the red one) is logged for components.css. Focus is never moved into a field automatically except to the first invalid field from the error summary link.

Labelling

Every field has a visible label; placeholders are examples, never the label. Hints, errors and counters are linked with aria-describedby in that order (error first). Prefix symbols are aria-hidden, so the label carries the unit: Budget gets a visually hidden in US dollars. Optional fields say (optional) in the label; required ones are the default and carry required with the form set to novalidate. Add autocomplete tokens for personal data and autocomplete="off" plus spellcheck="false" for identifiers.

Motion

The edge changes over --duration-fast with --ease-standard; reduced motion zeroes it in the tokens. Nothing else moves.

Touch

40px fields with the label as part of the target. inputmode="decimal" and "numeric" bring up number keypads; autocapitalize="off" stops phones capitalising logins and worker names. Value text is 14px; iOS zooms into fields under 16px, so the product steps fields to --text-body below lg (logged for components.css).

Content

  • Labels are nouns in sentence case with no colon: Name, Existing repository, Default budget per direction.
  • Hints state the rule or the default: 1–100 characters, unique among your projects, Default: .NET backend, Angular frontend.
  • Placeholders show an example value only (.NET + Angular) and never carry information the person needs after typing.
  • Errors say what is wrong and how to fix it, naming numbers: Default budget must be between $10.00 and $10,000.00.
  • Money always shows two decimals and a thousands separator: $10,000.00.
