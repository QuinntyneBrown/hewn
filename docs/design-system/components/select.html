Select

Selects choose one option from a list too long for radios: the product a feature is for, a token’s expiry, a log filter.

Overview

Use a native select for one choice from four or more options, or from a list that changes (products, projects). With two or three options that each need a description, use a radio group so every choice is visible; for filters that toggle a few views in place, a button group or Tabs. Hewn does not ship a custom listbox: the native control is accessible, works with every phone picker and needs no script.

  • Field select: inside a form field with a label above (Product, Expires).
  • With placeholder option: when there is no safe default, a first <option value="" disabled> such as Choose a product and required.
  • Inline filter (.inline-label + .select--auto.select--sm): label beside the control, above a list it filters (Stage on Decisions).
  • Filter with hidden label: when the first option names the filter (All projects, All actions), the label can be visually hidden but never omitted.

Anatomy

  1. Label.field__label with <label for>.
  2. Selected option--text-body-sm; padding --space-3 left, --space-8 right to clear the chevron.
  3. ChevronDrawn with two gradients in currentColor, so it follows the text colour in both themes and in forced colours.
  4. Hint.field__hint, linked with aria-describedby.

Responsive behaviour

  • Field selects fill their column at every breakpoint; long option text is cut with an ellipsis by the browser in the closed control and shown in full in the native picker.
  • Filter rows (.cluster) wrap under the page header below sm, each select keeping its content width; from md they sit to the right of the header text.
  • Phones show the native picker, which is always a large target; the closed control stays 40px (32px for filters, which are ≥ 24px with 8px between them).

Theming

Shares the field component tokens. The chevron uses currentColor, so it re-themes with --field-fg. color-scheme is set per theme in tokens.css, so the native option list is dark in the dark theme.

Accessibility

Role and pattern

Native <select>. If a custom list is ever needed (rich options, multi-select with chips), it follows the APG combobox or listbox pattern, not this component.

Keyboard

KeyAction
TabMoves to the select.
Space / Alt + ↓Opens the list.
↑ ↓Moves through options (on Windows, changes the value without opening).
Type a letterJumps to the next option starting with it (type-ahead).
Enter / EscChooses / closes without changing.

Focus

2px inset --field-ring. Changing the value never moves focus, navigates or submits (3.2.2): filters update the list below and announce 12 entries in a role="status" region.

Labelling

Every select has a label: visible above (fields) or beside (.inline-label), or visually hidden when the first option names the filter. Hints are linked with aria-describedby. Option text leads with the distinguishing word (Northwind Ops · northwind/ops-portal) so type-ahead works.

Motion

Only the edge transition (--duration-fast); the picker's animation belongs to the operating system.

Touch

Native pickers on iOS and Android give large targets and work with screen readers and switch access without extra code.

Content

  • Options are short and parallel; put the name first and context after a middle dot: Ledgerline · queues behind the running direction.
  • Order options by likelihood or a natural order (In 30 days, In 90 days, In 1 year sorted by duration), and say which is the default in the hint.
  • Filters start with All … as the first, default option.
  • Placeholder options are instructions in sentence case without a trailing ellipsis: Choose a product.
