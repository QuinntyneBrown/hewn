List

Lists stack short items of one kind: events as they stream in, pull requests, files in a commit, required checks, the stages that run next. Each item is a line or two, never a table row.

Overview

Use a list when items have one or two attributes and are read top to bottom. Use a row list when items carry several facts and actions; a Table when people compare columns; a Timeline when the items are steps in time.

  • Simple and two-line (.list, .list--divided): an icon, a title, an optional sub line.
  • Interactive (.list__link): each item is a link; the current one has aria-current.
  • Event stream (.events): time, project, kind and text in mono, newest first.
  • Pull requests (.pr): merged or open icon, title, project and number.
  • Files (.files): path, commit, time and a GitHub link, grouped under a stage heading.
  • Checks (.checks) and plan (.plan): a status icon per line with its output or duration on the right.
  • Mini list (.mini-list): caption-size lines inside dialogs and tiles.
  • Requirement links (.req-list): the traceability page's L2 picker.

Anatomy

  1. Leading iconA status icon (with its word, visually hidden), a file or folder icon, or a PR icon; 14–16px.
  2. Title.list__title, body-sm in --color-fg-default.
  3. Sub.list__sub, caption in --color-fg-subtle; metadata separated by middots.
  4. Divider.list--divided adds a hairline between items (decorative).

Responsive behaviour

  • Lists are one column at every width and never scroll sideways; long text truncates inside the item.
  • Event stream: time and text below sm; a 6.5rem project column joins from sm (36rem).
  • Files: path and commit on one line, time underneath, below sm; from sm a four-column grid (path, commit, time, open).
  • Requirement links: a horizontally scrolling strip of IDs with 44px targets below lg; a vertical list with titles and 32px rows from lg (62rem).
  • Interactive items stretch to the full width, so the whole line is the target on a phone.

Theming

Lists read the fg tokens for text, --color-border-default for dividers, --color-bg-subtle (links) or --color-bg-subtle-hover (PRs) for hover and --color-accent-subtle for the current item. Event kinds use the status fg tokens (--color-success-fg, --color-warning-fg, --color-fg-accent, --color-danger-strong). The requirement link hovers to --color-bg-surface-raised because it sits on the page canvas.

Accessibility

Role and pattern

<ul> for sets, <ol> for sequences (events, plan, timeline). Interactive items are native links, following the APG link pattern; the current one has aria-current="true" (or "page" when it is the page). Live lists: checks are aria-live="polite"; the event stream is aria-live="off" because it changes several times a second.

Keyboard

KeyAction

Focus

The shared ring on each link. In the requirement strip the current ID scrolls into view on load so it is not hidden off the edge.

Labelling

Icons that carry state are labelled: PR icons have role="img" and Merged or Open; status icons are followed by a visually hidden word (Running:). File open links name the file and commit: Open docs/estimates/README.md on GitHub at 19f4a8c. Event times are <time datetime>.

Motion

New events slide in at the top without animation; the list does not scroll under the reader. Running icons spin and stop under reduced motion; hover tints change over --duration-fast.

Touch

List links fill the width with 8px padding (at least 36px tall with two lines); requirement links are 44px below lg. The file's GitHub link is 32px; on phones the path should also be a link (see Do and don't).

Content

  • Titles are names or outcomes, not sentences: Split a transaction, backend · dotnet test.
  • Sub lines are metadata joined with middots: Ledgerline #27 · Merged 14 min ago.
  • Event kinds are lower-case single words (merge, spend, log, stage, decision, check, artifact).
  • Check details give the count and duration: 412 passed · 1m 48s; queued checks say queued.
  • Paths are repository-relative and folders end with a slash: docs/detailed-designs/reconciliation/.
