Logo

The Hewn mark is an H whose right pillar has had its corner hewn off; the chip that came away is the only colour in it. The wordmark pairs it with the lower-case name.

Overview

Use the wordmark once per screen as the product's signature: in the sidebar brand row and the mobile Top bar, where it links to the dashboard, and on sign-in, where it is static. Use the mark alone only where the name is already present or space is square (favicons, avatars for the Hewn system user in the audit log).

The mark is drawn from two brand tokens: --color-brand-body for the H and --color-brand-chip for the hewn-off corner. Nothing else about it changes.

Anatomy

  1. BodyLeft pillar, crossbar and the right pillar, .mark__body, filled with --color-brand-body.
  2. ChipThe hewn-off corner, .mark__chip, filled with --color-brand-chip.
  3. Name.wordmark__text: lower-case hewn, bold, 1.08em, tracked in by --letter-spacing-wordmark; aria-hidden.
  4. Clear spaceThe mark sits 0.34em from the name; keep at least half the mark's height clear on every side.

Sizes

The logo scales with font-size; the mark is 1em square and the name 1.08em. Use the three sizes below; never go below the small size.

hewn.wordmark20px (--font-size-xl)Sidebar brand row.
hewn.wordmark--lg24px (--font-size-2xl)Sign-in page.

Responsive behaviour

  • Below lg (62rem) the sidebar is hidden and the small wordmark sits centred in the 56px top bar.
  • From lg the medium wordmark sits in the sidebar brand row (64px tall, 20px side padding).
  • Sign-in uses the large wordmark at every width, top left of the form column.
  • The logo never scales fluidly with the viewport; it switches size only with the component that holds it.

Theming

Light: body --palette-slate-900, chip --palette-blue-600. Dark: body --palette-stone-200, chip --palette-blue-400. Both come from --color-brand-body and --color-brand-chip, so the mark inverts with the theme and the chip stays the accent blue. Do not recolour the mark for a single surface; if it must sit on an inverse surface, override both brand tokens on that container.

Accessibility

Role and pattern

Inline SVG, aria-hidden, inside a wrapper that carries the name: <a aria-label="Hewn, go to dashboard"> when it links, <span role="img" aria-label="Hewn"> when it does not. The visible hewn text is aria-hidden so the name is not read twice. See 1.1.1 Non-text content.

Keyboard

KeyAction
TabFocuses the wordmark link (first in the sidebar, second in the top bar after the menu button).
EnterGoes to the dashboard.

Focus

Shared focus ring round the whole wordmark with the 2px offset.

Labelling

Linked: Hewn, go to dashboard. Static: Hewn. Never add a separate visible Hewn next to it.

Motion

None. The mark never animates.

Touch

In the top bar the wordmark link is the full 56px bar height and about 80px wide.

Content

  • The product name is Hewn in running text and accessible names; the lower-case hewn appears only inside the wordmark.
  • The dashboard screen is Mission Control; do not put that name in the logo.
  • Version lines go near the logo as caption text, not inside it: Hewn 0.9.2 · MIT.
