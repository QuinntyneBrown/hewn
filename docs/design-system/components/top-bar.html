Top bar

The phone and tablet header: a menu button that opens the navigation drawer, the wordmark home link and the live connection dot. From lg the sidebar takes over and the top bar disappears.

Overview

Every shell page renders the top bar above its strips and <main>. Below --layout-breakpoint-lg (992px) it is the only navigation chrome on screen: the sidebar is hidden and the menu button opens the same sidebar inside a Drawer. From lg it is display: none, because the sidebar is always visible.

  • Menu button: icon-only, 44px, opens the navigation drawer (the mobile-nav dialog). It is the main target on a phone.
  • Wordmark: the small Hewn wordmark, a link to the Dashboard named Hewn, go to dashboard.
  • Connection dot: the same Live / Reconnecting / Offline state the sidebar footer shows, as a dot with an accessible name. The wording lives in the strip below the bar when the connection is not live.

The top bar holds nothing else: no search, no tabs, no page actions. Page actions stay in the Page header; project sections stay in the Project header tabs.

Anatomy

  1. Menu button.btn--ghost.btn--icon.btn--touch, 44px, aria-label="Open menu", aria-haspopup="dialog", aria-expanded.
  2. Wordmark.wordmark--sm (18px) inside an <a> to the Dashboard; the SVG and text are hidden, the link is named.
  3. Connection slot.topbar__slot: a 44px cell, role="img" with aria-label="Connection: Live", holding a .dot.
  4. Bar.topbar: --layout-topbar-height (56px), sticky at --z-sticky, surface background, hairline bottom border, --space-3 side padding.

.topbar--always keeps the bar visible from lg too, with --space-8 side padding. Only documentation and embedded previews use it; the product hides the bar from lg.

  • Expanded: while the drawer is open the button reports aria-expanded="true" and the shell behind is inert, so the button is not reachable again until the drawer closes; Close inside the drawer returns focus to it.
  • Reconnecting pulses at --duration-pulse; under reduced motion the pulse stops and the dot stays amber.

Responsive behaviour

  • Below --layout-breakpoint-sm (576px) and from sm to md (768px): the bar shows, full width, sticky at the top; strips stack under it; the page scrolls under the sticky bar (scroll-padding-top: var(--layout-topbar-height) keeps anchored headings visible).
  • From md to lg (992px): unchanged. Tablets still use the drawer, because the 15rem sidebar plus the pipeline rail would squeeze the stage detail below its measure.
  • From lg: display: none. The sidebar is visible and carries the same three things (brand, navigation, connection).
  • xl (1200px) changes nothing. The bar never grows extra content as the screen widens.

Theming

The bar uses only semantic tokens: --color-bg-surface for the background, --color-border-default for the bottom hairline, the ghost button's tokens for the menu button and the status solids for the dot. In dark the surface lifts above the canvas and the hairline darkens, so the bar still reads as a separate layer without a shadow.

/* An embedded preview that keeps the bar at every width */

Accessibility

Role and pattern

A <header> outside <main>, so it is the page's banner landmark. The menu button follows the APG modal dialog pattern for its trigger: a real <button> with aria-haspopup="dialog", aria-expanded and aria-controls pointing at the drawer.

Keyboard

KeyAction
TabFrom the skip link, moves to the menu button, then the wordmark, then into the strips and page.
Enter, SpaceOn the menu button: opens the drawer and moves focus to its Close button.
EscInside the drawer: closes it and returns focus to the menu button.
EnterOn the wordmark: goes to the Dashboard.

Focus

The shared 2px ring with 2px offset on :focus-visible. The bar is sticky, so a focused element in the page is never hidden under it: scroll-padding-top equals the bar height (WCAG 2.4.11 Focus Not Obscured).

Labelling

Open menu on the button (not Menu or Hamburger); Hewn, go to dashboard on the wordmark link; Connection: Live / Reconnecting / Offline on the dot. Changes in connection are announced by the strip (role="status" for reconnecting, role="alert" for offline), not by the dot.

Motion

Only the reconnecting dot moves (opacity pulse at --duration-pulse); reduced motion zeroes it. The drawer's slide-in belongs to the drawer.

Touch

The menu button and the connection slot are 44 × 44px (--target-comfortable); the wordmark link is 18px tall but sits alone in the middle with at least 24px of clear space on each side (WCAG 2.5.8 spacing exception).

Content

  • The bar has no visible text other than the wordmark. Do not add page titles: the page header below already has the <h1>.
  • Accessible names are verb first for actions (Open menu) and say the destination for the brand link (Hewn, go to dashboard).
  • Connection names use the same three words as the sidebar footer: Live, Reconnecting, Offline.
