Component · Data display

Table

Tables lay out records people scan and compare column by column: who did what in the audit log, which runs a stage needed. One row per record, one column per attribute.

Overview

Use a table when the reader compares the same attribute down many rows: timestamps, actors and IPs in the audit log, statuses and durations of a stage's runs. Use a row list when each row is an object people open or act on and it must read well stacked on a phone (projects, backlog, workers). Use a List when a row has one or two attributes.

  • Default: the audit log. Absolute timestamps in mono, low-priority columns hidden on small screens with .col-sm / .col-md.
  • Runs: a stage's attempts with a status cell and a right-aligned duration.
  • Dense: .table--dense for long logs inside a tile or rail.
  • Sortable: header buttons with aria-sort; one column sorted at a time.
  • Sticky header: .table--sticky inside a height-capped wrapper.
  • Traceability matrix: one requirement traced across four fixed columns (designs, journeys, acceptance tests, pull requests). It is a grid of lists, not a <table>, because each column has its own length.

Anatomy

  1. Caption<caption>, visually hidden when the page heading already says what the table is; it names the sort order.
  2. Header cell<th scope="col">, --text-caption medium in --color-fg-subtle, never wraps.
  3. Body cell--text-body-sm, padding --space-3 block, --space-4 trailing; mono for timestamps, IDs and IPs.
  4. Numeric cell.num: right-aligned, tabular figures, no trailing padding.
  5. Row ruleHairline --color-border-default under every row (decorative, exempt from 1.4.11).

Responsive behaviour

  • Every table sits in .table-wrap, which scrolls horizontally inside its own box; the page never scrolls sideways at 360px.
  • Base (phones): only the columns needed to identify and read the record. .col-sm cells appear from sm (36rem), .col-md from md (48rem).
  • When a column is hidden, its value moves into a cell that stays: the audit log's Target becomes a caption line under the Action (.sm-hide).
  • The traceability matrix is one column below md, two from md (48rem) and four from xl (75rem); it never scrolls.
  • If a table has four or fewer columns and every row is something people open, use a row list instead: it stacks rather than scrolls.

Theming

The table reads semantic tokens directly: header ink --color-fg-subtle, rules --color-border-default, hover --color-bg-subtle, selected --color-accent-subtle. In dark the rules become --palette-slate-700 and the hover tint lifts the row a step, so hover and selection read without borders getting brighter.

The sticky header paints --color-bg-canvas so rows slide under it. A sticky table placed on a card must paint the card's surface instead; set it on the wrapper's context rather than editing .table.

/* A sticky table inside a tile body */
.tile .table--sticky thead th { background: var(--color-bg-surface); }

Accessibility

Role and pattern

Native <table> with a <caption> and <th scope="col">; no ARIA grid, because cells are not individually interactive. Sort buttons live inside the header cell and the cell carries aria-sort, as in the APG sortable table example of the APG table pattern. The traceability matrix is an <ol> of columns, each with a heading and a count.

Keyboard

KeyAction
Tab / Shift + TabMoves between links and sort buttons inside the table, in reading order, then to the scroll wrapper when it can scroll.
Enter, SpaceOn a sort button: sorts by that column; pressing again reverses the order.
← →With the scroll wrapper focused: scrolls hidden columns into view.
Screen reader table keysMove cell by cell with headers announced, because the header cells are real th with scope.

Focus

The shared focus ring on links and sort buttons. A wrapper that can scroll gets tabindex="0", role="region" and a name, so keyboard users can reach columns that do not fit; it shows the same ring.

Labelling

The caption names the table and its order (Audit log, newest first) and may be visually hidden when the page heading says the same. After sorting, the caption updates (Audit log, sorted by who, A to Z) so the change is announced. Empty cells hold an em dash (—), never nothing, so a screen reader does not read the next cell as this one. Status cells carry the word, not just the icon.

Motion

Row hover fades its tint over --duration-fast; reduced motion makes it instant. The Running status icon spins and stops under reduced motion. Skeleton rows shimmer on --duration-pulse, which reduced motion sets to 0s.

Touch

Rows are not tap targets; links inside cells are. Make the record's identifying text the link so the target is the full text width, at least 24px tall with the default row padding. Horizontal scroll in the wrapper uses the native swipe.

Content

  • Column headings are short nouns in sentence case: When, Who, Action, Target, IP, Duration.
  • Audit timestamps are absolute and complete (9 Nov 2026, 14:31:07) because entries are evidence; feeds may use relative time.
  • Numbers, durations and money are right-aligned with tabular figures: 3:12:48, $184.20.
  • An empty value is an em dash (—). The Merge entry has no IP because the merge came from GitHub, not a browser.
  • Statuses are the status words (Running, Failed), never ad-hoc labels such as Error or OK.
