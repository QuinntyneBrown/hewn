Dashboard tile

Dashboard tiles are the panels of Mission Control’s home: a 44px header with title, meta and an Open link, and a body that scrolls inside the tile. They sit on a 12-column grid that the Owner can rearrange.

Overview

Use a tile for one live summary on the dashboard: live work, items that need attention, the event stream, pull requests, spend, workers. Each tile answers one question at a glance and links to the page that answers it in full. Elsewhere, use a Card.

  • Standard: 14rem minimum height below lg; from lg its height is its row span on the grid (3.75rem rows).
  • Compact (.tile--compact): 8rem minimum below lg, for one figure or a short list (Spend, Workers).
  • Body kinds: a divided list (.tile__body.divided: Live work, Needs attention, Pull requests), a log-like list (.events), a stat (.spend) or a mini list (.mini-list).
  • Edit mode (.dash--edit on the grid, .tile--edit on movable tiles, .tile--locked on fixed ones): desktop only, with a resize handle and keyboard moves.

Anatomy

  1. Title.tile__title, an <h2> that names the region; --text-h3.
  2. Meta.tile__meta: a count or time (Today, 3 of 4 online), caption, truncates.
  3. Open link (optional).tile__open: to the full page, 28px tall, pushed to the end.
  4. Body.tile__body: fills the rest and scrolls vertically inside the tile.

Variants

The dashboard grid

.dash stacks tiles in reading order below lg. From lg it is a 12-column grid with --layout-dash-row rows and a fixed placement per tile (widen the window past 62rem to see it).

States

The header link has hover and focus. In edit mode a movable tile is focusable (the ring is drawn around the tile) and shows its resize handle; a locked tile has a stronger neutral ring and a lock icon instead.

Responsive behaviour

  • Base to md: one column in reading order (Live work, Needs attention, Event stream, Pull requests, Spend, Workers), 8px apart; tiles size to content with a 14rem (compact 8rem) minimum.
  • From --layout-breakpoint-sm (576px) the event list shows the project column and Live work shows the worker name.
  • From --layout-breakpoint-lg (992px): the 12-column grid with fixed placements; tile height comes from its row span and the body scrolls.
  • Edit layout is desktop-only: the Edit layout button is .lg-only and below lg the dashboard leaves edit mode.

Theming

Tiles read --tile-ring (default --color-border-default) and --tile-shadow (default --shadow-1). Edit mode sets --tile-ring: --color-accent and --tile-shadow: --shadow-2; locked sets --tile-ring: --color-border-strong. The edit grid lines are --color-border-grid.

In dark the shadow tokens deepen and the surface sits a step above the canvas, so tiles separate from the page by lightness; the accent ring in edit mode lightens with the accent.

Accessibility

Role and pattern

Each tile is a <section> named by its <h2> title through aria-labelledby, so it is a region landmark screen-reader users can jump between. In edit mode, movable tiles take tabindex="0" and aria-roledescription="movable tile"; dragging always has the keyboard alternative below (SC 2.5.7). Live lists do not announce: the event stream is aria-live="off" and status changes go through the shell’s throttled status region.

Focus

Links in the header and body show the shared ring. A focused movable tile shows the ring around the whole tile, outside its accent edge.

Labelling

The Open link adds the tile name as visually hidden text (Open workers, Pipeline live work), so it makes sense in a links list. The lock icon is an image named Locked tile; the resize handle is named Resize Spend. Charts carry a text alternative (Spend for the last 7 days, $512.70 this week).

Motion

No tile animation. The spinning stage icon and pulsing segment are loops on --duration-pulse/--duration-spin, stopped under reduced motion.

Touch

The resize handle is 24px (--target-min); edit mode is pointer-and-keyboard desktop only. The Open link is 28px tall in a 44px header.

Content

  • Titles are two-word nouns: Live work, Needs attention, Event stream.
  • Meta is a count or a time window with tabular figures: 2 running, 9 merged today, 3 of 4 online.
  • Empty bodies say what will appear and when: Events stream in here as soon as a worker leases a run.
  • Error bodies say what failed and that the rest still works: The event store timed out. Other tiles are live.
