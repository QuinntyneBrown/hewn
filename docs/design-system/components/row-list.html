Row list

Row lists show the objects people open and act on (projects, increments, workers, users) as rows that line up in columns on a laptop and stack into readable cards on a phone.

Overview

Use a row list when each row is a thing with a name the reader opens, a status, a few facts and maybe row actions, and it must stay readable at 360px without sideways scrolling. Below lg every row is a small two-column card; from lg the same cells line up under a column head. Use a Table when people compare columns (the audit log) and scrolling is acceptable; use a List for one-line items.

  • Projects (.rows--projects): name and idea, stage, status, percent complete, spend, last activity, archive and delete. Viewers get .rows--projects-viewer without the actions column.
  • Backlog (.rows--backlog, an <ol>): number, increment, journey, requirements, estimate, status, PR. The increment in progress is .row--current.
  • Workers (.rows--workers): host and ID, location, version, status, what it is working on, heartbeat, connected time, Revoke. Viewers get .rows--workers-viewer.
  • Users (.rows--users): avatar and login, role, last sign-in, Remove.

Anatomy

  1. Title and sub.row__title (the link, body medium) over .row__sub (body-sm muted, truncates).
  2. StatusBelow lg in the top-right cell (.lg-hide); from lg in its own column (.lg-only).
  3. Spanning line.row__span takes the full width on phones: stage and .row__note.
  4. FactsMeter, money, times: tabular, with a visually hidden prefix (Spend) because the column head is hidden from screen readers.
  5. End cell.row__end: right-aligned numbers.
  6. Row actions.row__actions: 44px icon actions on phones, 32px from lg; a full-width bar below the facts on phones.

Sizes

Row lists have one density: 16px block padding stacked, 12px in columns (backlog rows are 12px at every width). Use a dense table for long logs.

States

Rows are not focusable; the title link is. A row with .row--interactive tints on hover because the whole row opens its object; a row without it only underlines its title link. The current row (the increment being built) takes the accent tint.

Responsive behaviour

  • Base (below lg, 62rem): each row is a two-column grid, minmax(0, 1fr) auto: title and sub left, status right; .row__span and .row__actions take the full width; .lg-only cells are hidden and .lg-hide duplicates (the status) show.
  • Backlog rows below lg: a 32px number column, the title, and the status; journey, requirements and PR stack under the title in column 2 (.col2).
  • From lg: .rows__head appears and each variant applies its column template (projects: 2.2fr 1.3fr 8rem 7rem 7rem 6rem 6rem, the last wide enough for Restore; workers: 1.6fr 6rem 5rem 7.5rem 1fr 6rem 6rem 5rem; users: 1fr 8rem 10rem 6rem), so cells line up as columns.
  • Row actions are 44px (--target-comfortable) below lg and 32px (--control-height-sm) from lg.
  • Text truncates with an ellipsis inside its cell; the row never scrolls horizontally.

Theming

Rows read --color-border-default for the rule, --color-bg-subtle for hover and --color-accent-subtle for the current row; text inks are the semantic fg tokens. Column templates are layout geometry in rem and live with each variant; a new row list adds a .rows--name template, it does not restyle .row.

/* A new row list: deployments */
@media (min-width: 62rem) {
  .rows--deploys .rows__head, .rows--deploys .row { grid-template-columns: minmax(0, 2fr) 8rem 6rem 6rem; }
}

In dark the current-row tint is --palette-blue-950-deep and its text stays --color-fg-default (4.77:1 after the drift fix).

Accessibility

Role and pattern

A plain <ul> (or <ol> when order means something, as in the backlog) of <li class="row">; screen readers announce “list, 3 items”. The visual column head is aria-hidden, so every cell must make sense on its own: words in the cell (Journey 4, 2.5 d, Last sign-in: Today, 08:02) or a visually hidden prefix (Spend, Heartbeat). See the APG note on structural roles (list, listitem). Do not use role="table" or role="grid" on a row list.

Keyboard

KeyAction
Tab / Shift + TabTitle link, then each row action, then the next row.
EnterOpens the row's object (the title link) or activates a focused action.
SpaceActivates a focused row action button.
Screen reader list keysJump between rows as list items; each item reads title, sub, status, facts and actions in order.

Focus

The shared ring on the title link and on each action. Unavailable actions (aria-disabled="true" on role="button") stay focusable so their name can say why: Delete Ledgerline: cancel the running direction first. After Archive or Delete, focus moves to the next row's title, or to the list heading if it was the last row.

Labelling

The title link's text is the object's name. Icon actions carry the verb and the object (Archive Field Notes). The percent meter has aria-label="Ledgerline complete". Duplicate status cells are fine: only one is displayed at a time and display: none removes the other from the accessibility tree.

Motion

Hover tint fades over --duration-fast. Rows update in place as events arrive (status, percent, spend) without moving; a row that changes position (re-sorting by activity) does so on the next load, never under the pointer. Reduced motion stops the Running spinner and the skeleton shimmer.

Touch

On phones the title is the main target; icon actions are 44px with 4px between them. Hover-only affordances do not exist: tooltips duplicate the accessible name and are not needed to understand the row.

Content

  • The title is the object's name as the person gave it (Kiln Booking); the sub is its one-line idea, cut with an ellipsis, never wrapped.
  • The spanning line says where it is and what is happening: 10 · Increments then the note Increment 7 of 12 · implementing, iteration 3.
  • Relative times for activity and heartbeats (4s ago, 42m ago, Yesterday); absolute dates once older than a week (12 Oct).
  • Empty facts say why: Waiting for work, Lease released, Never, not a blank.
  • Numbers are tabular; money always has two decimals ($250.00); estimates in ideal days with a unit (2.5 d).
