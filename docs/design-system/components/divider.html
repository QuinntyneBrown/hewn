Divider

Dividers are hairlines that separate groups when spacing alone is not enough: between list rows, around tile headers and footers, between a main column and its rail.

Overview

Reach for space first (see Spacing); add a divider when items of the same kind sit close together and need a boundary (rows of a list, a header bar above content). Most Hewn dividers are built into components: .divided lists in tiles, .card__header/__footer, .sidebar__foot, .split--aside > .rail. Use the standalone classes only between page sections.

  • Horizontal (<hr class="divider">): between sections; 24px above and below.
  • Vertical (.divider--vertical): between inline groups in a cluster.
  • With label (.divider--label): a caption between two rules, for a time group in a long list.
  • Divided list (.divided): a hairline between every child, none above the first.

Anatomy

  1. Rule1px (--border-width-hairline) --color-border-default.
  2. Label (optional)--text-caption, --color-fg-subtle, 12px from each rule.
  3. RuleFlexes to fill the remaining width.

Sizes

One weight: the 1px hairline. The 2px --border-width-thick is reserved for the stage rail and current-tab underline, which are indicators, not dividers.

States

Dividers are static: they have no hover, focus or selected state.

Responsive behaviour

  • Horizontal dividers span their container at every breakpoint.
  • Rails: .split--form > .rail gains a vertical hairline from lg and .split--aside > .rail from xl, when the rail moves beside the main column; below that the rail stacks and the hairline disappears (space separates it).
  • Vertical dividers in a cluster disappear when the cluster wraps onto two lines; prefer a gap at 360px.

Theming

Dividers read --color-border-default and --border-width-hairline. In dark the border token is a light step above the surface, so hairlines stay faint but visible. Forced-colours mode maps them to CanvasText via the border, so they stay visible there too.

Accessibility

Role and pattern

A section divider is <hr> (implicit role="separator"). A purely visual hairline (list rows, header bars) is a border, not an element, so it is not announced. A vertical divider between groups is role="separator" aria-orientation="vertical". See WAI-ARIA separator; a static separator is not focusable.

Keyboard

KeyAction
TabNot focusable; focus passes over dividers.

Focus

Dividers never take focus.

Labelling

A labelled divider’s label is plain text and is read as such. Do not put meaning only in the line: a group needs its own heading or label.

Motion

None.

Touch

Not interactive. The hairline is decorative (exempt from 1.4.11); it does not need 3:1.

Content

  • Divider labels are short time or group names in sentence case: Earlier today, Yesterday.
  • Never a divider label as a heading for content that needs navigation: use a real heading.
