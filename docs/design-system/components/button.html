Button

Buttons start, stop, approve and confirm work. One primary button per view says what the view is for.

Overview

Use a button when activating it changes something: it starts a direction, pauses or stops workers, raises a budget, deletes a project or opens a dialog. Use a Link when it only goes somewhere. Use a Menu when one trigger offers several actions, and a Button group for a small set of mutually exclusive options.

  • Primary: the one action the view exists for (Start direction, Save changes). Never two per view.
  • Secondary (no modifier): every other action that still matters (Pause, Cancel).
  • Ghost: inside dense surfaces such as tile headers, rows and toolbars (View all, Remove).
  • Outline accent: a positive action that should stand out without being the primary (Resume on a paused project).
  • Danger: destructive actions, and only inside a confirmation dialog or after one (Delete project, Stop all workers).
  • Link: a low-emphasis action inside text or a callout (Retry, Show details).
  • Stone: the inverse, high-contrast button used once, on sign-in.

Anatomy

  1. Leading icon (optional)16px (14px in small buttons), inherits the label colour, aria-hidden.
  2. LabelA verb phrase in sentence case; it is the accessible name.
  3. ContainerHeight --control-height-*, --radius-md, 1px inset ring, padding --space-3/4/6.

Variants

Variants change emphasis, not meaning. Pick by how much attention the action deserves on this view.

From highest to lowest emphasis; danger is reserved for destructive confirmations, stone for sign-in.

Sizes

Medium is the default. Small lives in rows, tile headers, callouts and toolbars; large is for sign-in and empty-state calls to action.

Heights --control-height-sm/md/lg; padding --space-3/4/6; label --font-size-xs/sm/md.
HTML
<button class="btn btn--primary btn--sm" type="button">Small · 32px</button><button class="btn btn--primary" type="button">Medium · 40px</button><button class="btn btn--primary btn--lg" type="button">Large · 48px</button>

.btn--touch on an icon-only button grows it to 44px (--target-comfortable) below lg, where it is the main target on a phone (the top bar's menu button).

Pressed and expanded

Toggle buttons use aria-pressed; menu buttons use aria-expanded. Both take the accent tint when on.
HTML
<button class="btn btn--sm" type="button" aria-pressed="true">Follow log</button><button class="btn btn--sm" type="button" aria-pressed="false">Follow log</button><button class="btn" type="button" aria-expanded="true" aria-haspopup="menu">More <svg class="icon" viewBox="0 0 24 24" aria-hidden="true"><path d="m9 18 6-6-6-6"/></svg></button>

Both themes

  • Busy sets aria-busy="true" and aria-disabled="true" (not disabled, so focus stays on the button), spins the leading icon and changes the verb to its progressive form: Delete project → Deleting…. Further clicks are ignored.
  • Disabled uses the native attribute: not focusable, 50% opacity. Prefer leaving the button enabled and explaining on activation when the reason is not obvious; for Viewers, hide owner-only actions rather than disabling them.

Responsive behaviour

  • Below --layout-breakpoint-sm (576px) the page header stacks and its primary action sits under the title; on sign-in the stone button is full width (.auth__btn).
  • In dialog footers buttons stack full width below sm with the primary on top (column-reverse), and sit in a row, primary last, from sm up.
  • Icon-only buttons in the top bar and rows use .btn--touch or .icon-action, which are 44px below lg and 32–40px from lg.
  • Labels never truncate or wrap; a label that wraps at 360px is too long. Shorten the verb phrase.

Theming

The button reads semantic tokens through component tokens that each variant overrides: --btn-bg, --btn-fg, --btn-ring, --btn-bg-hover, --btn-bg-active, --btn-height, --btn-pad, --btn-radius. A theme changes semantic tokens; a re-skin overrides component tokens; neither edits the component CSS.

/* A taller, rounder primary for a marketing surface, without touching .btn */
.promo .btn--primary { --btn-height: var(--control-height-lg); --btn-radius: var(--radius-full); }

In dark the accent lightens to --palette-blue-400 and its label flips to near-black --palette-blue-950; the danger button becomes a deep red tint with a light red label and a red ring, so it reads as raised without glowing.

Accessibility

Role and pattern

Native <button type="button">, or type="submit" in a form. A button that only navigates is an <a href> with the same classes. No ARIA role is needed; see the APG button pattern for toggle (aria-pressed) and menu (aria-expanded) buttons.

Keyboard

KeyAction
Tab / Shift + TabMoves focus to and from the button in DOM order.
Enter, SpaceActivates. Space fires on key up, so moving away cancels a mis-press.
EscNo effect on the button; inside a dialog it closes the dialog.

Focus

The shared ring (2px --color-focus-ring, 2px offset) appears on :focus-visible only. The offset gap shows the surface behind, so the ring stays ≥ 3:1 against both the primary fill and the page. A busy button keeps focus.

Labelling

The visible label is the name. Icon-only buttons set aria-label with the verb and object (Refresh workers, Open navigation) and show a tooltip. Busy buttons keep their name; the progressive label (Deleting…) is read when focus is on them, and the outcome is announced by a toast or the dialog closing.

Motion

Background and colour transition over --duration-fast; active scales to 98%. Under reduced motion the durations are zeroed in the tokens and the busy spinner stops (the icon and the progressive label still say it is working).

Touch

Medium (40px) and large (48px) clear the 24px minimum; small (32px) is used only inside rows and headers with ≥ 8px between targets. Icon buttons that are a phone's main target grow to 44px.

Content

  • Verb first, sentence case: Start direction, Raise budget, Stop all workers, Copy token. Never OK, Yes, Submit.
  • Name the object when the context does not: Delete project in the dialog, Remove in a user row.
  • Destructive labels say what is lost: Revoke wk-4e18, not Confirm.
  • Busy labels use the progressive form with an ellipsis character: Saving…, Stopping workers….
  • Keep to three words; numbers in labels are tabular: Raise to $500.
