Stepper

Steppers show where work is in a fixed sequence. Hewn has two: the eleven-stage pipeline list you can open stage by stage, and the five-step progress bar of an increment.

Overview

Pipeline stage list (.stages): the eleven stages every direction runs, Bootstrap to Increments. Each stage is a link that opens its detail beside the list, with its number, name, duration and a status icon plus hidden word. It is the project page's main navigation and changes shape with the screen (L2-046).

Progress steps (.steps): five bars under the current increment — Tests written, Implement, Video, Pull request, Merge — with the step in progress labelled (iteration 3 of 10). They are read-only: progress, not navigation.

Use the Pipeline strip for a ten-segment summary of the same stages in a list row or tile, and a Timeline for what happened, in order, with times.

Anatomy

  1. Status icon16px status icon (check, spinner, cross, pause, dashed, slash); the word is visually hidden after the name.
  2. Number.stage__n, code type, subtle: 0 to 10.
  3. Name.stage__name, truncates; skipped stages are struck through and subtle.
  4. Duration.stage__dur, tabular, from lg only; — for stages that have not run.
  5. Current markeraria-current="step": accent edge (left in the column, bottom in the row) and raised background.

Responsive behaviour

  • Below --layout-breakpoint-sm (576px): the stage list is a vertical list above the stage detail, full width, accent edge on the left (L2-046 AC1). Durations and the live line are hidden.
  • sm (576px) to lg (992px): a horizontal, scrollable stepper above the detail: each stage 11rem wide, accent edge on the bottom, bleeding to the screen edge (L2-046 AC2).
  • From lg (992px): a vertical rail beside the detail (.split--pipeline, 18rem, then --layout-rail-pipeline 20rem from xl 1200px) with durations and, on the running stage, the live step and last command (L2-046 AC3).
  • Progress steps stay one row of five at every width; the sub-label (iteration 3 of 10) shows from sm, and step names truncate on phones.

Theming

Stages use --color-border-default for the resting edge, --color-accent for the current edge, --color-bg-surface-raised for the current fill and --color-bg-subtle on hover. Progress bars use the status solids: --color-success-solid, --color-accent, --color-warning-solid, --color-danger-icon, on a --color-border-default track. In dark the raised fill lifts the current stage above the canvas, and the solids are the lighter dark-theme values, so the bars keep 3:1 against the card.

Accessibility

Role and pattern

No APG widget; both are ordered lists (<ol>) with an aria-label, and the current item uses aria-current="step". The stage list's items are links (each stage has its own URL); the progress steps are static list items. Status is always an icon plus a word, never colour alone (L2-030).

Keyboard

KeyAction
TabStage list: through each stage link, 0 to 10. Progress steps: not focusable.
EnterOpens that stage's detail; focus moves to its heading (9 Estimates).

Focus

The shared ring around the stage. In the horizontal stepper (sm–lg) a focused stage is scrolled into view, and on load the current stage is scrolled into view so the running stage is not off screen.

Labelling

Lists are named Pipeline and Increment steps. A stage reads 9 Estimates 5:37 Succeeded, current step. Each progress step reads its name and state (Implement, In progress, current step; Video, Not started). The live line on the running stage is not a live region; the log below is.

Motion

The running stage's icon spins (.icon--spin, --duration-spin); hover backgrounds fade over --duration-fast. Reduced motion stops the spinner; the word Running still says it.

Touch

Each stage is a full-width row at least 44px tall below lg, and an 11rem by 44px cell in the horizontal stepper, scrolled with the native gesture.

Content

  • Stage names are fixed: Bootstrap, Idea, Designs, Design system, Stack, Requirements, Scaffold, Detailed designs, User journeys, Estimates, Increments. Numbered from 0.
  • Durations are m:ss or h:mm:ss, tabular; — when a stage has not run.
  • Progress step names are nouns or short verb phrases: Tests written, Implement, Video, Pull request, Merge.
  • The sub-label says how far into the current step: iteration 3 of 10, blocked after 10 iterations.
