Skip link

The first thing in every page: a link that jumps keyboard and screen-reader users past the sidebar and top bar to the main content. Invisible until it is focused.

Overview

Every one of the 154 mock states, and every page of this design system, starts with <a class="skip-link" href="#main">Skip to content</a> as the first focusable element, pointing at <main id="main">. Pressing Tab once on load reveals it in the top-left corner; Enter moves focus past the sidebar's 15 or so stops (brand, New direction, five links, four projects, Stop all workers) or the top bar.

It is the only skip link. Hewn's landmarks (banner, navigation, main) and headings handle the rest; extra links such as Skip to log are not needed.

Anatomy

  1. Container--color-bg-inverse fill, --radius-md, --space-2 / --space-3 padding, at --z-tooltip so nothing covers it.
  2. LabelSkip to content in --text-label, --color-fg-inverse.

Variants

One variant. It is shown here with .skip-link--static, which places it in the flow so it can be seen without focusing it; the product never uses that modifier.

The link is moved off screen with a transform, not display: none or visibility: hidden, so it stays focusable; on focus the transform is removed and it appears instantly.

Responsive behaviour

  • Identical at every breakpoint (xs, sm 576px, md 768px, lg 992px, xl 1200px): pinned --space-2 from the top-left corner of the viewport, above the sticky top bar.
  • Below lg it lands focus past the top bar; from lg, past the sidebar. The target is the same #main.

Theming

It uses the inverse pair, --color-fg-inverse on --color-bg-inverse: dark on light pages and light on dark pages, so it always contrasts with whatever it overlaps. Nothing else is themeable; do not brand it.

Accessibility

Role and pattern

A same-page link meeting WCAG 2.4.1 Bypass Blocks. The target <main id="main"> takes focus when followed (browsers move the sequential focus start point to it; add tabindex="-1" to <main> if a framework router intercepts the hash).

Keyboard

KeyAction
TabFirst press on page load focuses and reveals it.
EnterMoves focus to the start of <main>; the next Tab is the first control in the page.
Tab againWithout pressing Enter: hides it and continues to the menu button or sidebar.

Focus

The shared 2px ring with 2px offset around the inverse pill, against the page canvas. In an Angular app, re-focus the skip link's target (or the new <h1>) after route changes; the skip link itself stays first in the document.

Labelling

Skip to content: says what it does. Not Skip navigation (on phones there is no visible navigation to skip) and not Main content (no verb).

Motion

None: it appears and disappears instantly, so there is no transition to reduce.

Touch

Touch users rarely meet it, since it is only shown on keyboard focus; when shown it is about 36px tall with nothing else within 24px.

Content

  • Exactly Skip to content, sentence case, on every page.
  • Do not translate it into an instruction (Press Enter to skip).
