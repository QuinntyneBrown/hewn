Status and badge

Status words tell people what a project, stage, run, worker or check is doing: always an icon and a word, in one of six tones. Pills, counts and dots are the smaller signals around them.

WCAG 2.2 AAStatus: stableIcon + word, never colour alone

Overview

Every status in Hewn is one of seventeen fixed words, each with a fixed icon and tone (L2-030). Use the status component wherever one appears: project rows, stage titles, run tables, worker rows, the increment timeline. Use a pill for a flag or note that is not a status (No acceptance test), a count for a number beside a label (Running 2), and a dot only next to text that already says the state (Live). For filter or tag controls use a Chip.

  • Run (accent, spinning loader): Running, In progress, Leased.
  • Ok (success, check): Succeeded, Merged, Complete.
  • Fail (danger): Failed and Blocked (x in circle), Offline (no wifi).
  • Warn (warning, pause): Paused, including Budget reached as a custom label.
  • Idle (muted, dot in circle): Idle.
  • Muted (subtle): Pending and Queued (dashed circle), Skipped (slashed circle), Cancelled (ban), Deferred (minus), Archived (archive box).

Anatomy

  1. Status icon16px (12px small), the tone's icon colour; spins for the run tone.
  2. Status word--text-label in the tone's fg colour; it is the accessible text.
  3. PillTinted background, --radius-sm, body-sm text, optional 14px icon.

Responsive behaviour

  • Status words never wrap or truncate (white-space: nowrap); they are short by design.
  • In row lists the status moves from the top-right cell (below lg) to its own column (from lg); it is the same component.
  • Pills wrap their text only when longer than the line, which a pill should not be.

Theming

Each tone maps to semantic status tokens: text --color-*-fg, icons --color-*-icon (via .s-icon--*), pill backgrounds --color-*-bg, dots --color-*-solid. Run uses the accent (--color-fg-accent). In dark the fg tokens lighten (green-400, amber-400, red-400, blue-400) and the backgrounds deepen, so text keeps 4.5:1 and icons 3:1. The light warning fill moved to amber-600 so warning dots and meters reach 3:1 (see the drift log).

Accessibility

Role and pattern

Static text: a <span class="status"> holding an aria-hidden icon and the word. No ARIA widget pattern applies; the rule is WCAG 1.4.1 Use of Color and the APG structural roles guidance. Containers whose statuses change while people watch (required checks) are aria-live="polite"; a page-level status change is announced by a toast, not by the badge.

Keyboard

KeyAction
TabSkips status, pills, counts and dots; none is focusable.

Focus

None. A status inside a link (a project row) is part of the link's name.

Labelling

The word is the label. Icon-only uses keep the word visually hidden (status("Deferred", ""), or a hidden Running: before a check name). Counts are preceded by a hidden comma, so Running, 2 is read rather than Running2. Dots are decorative.

Motion

The run loader spins (--duration-spin, linear); the reconnecting dot pulses (--duration-pulse). Both are zeroed under reduced motion.

Touch

Not targets. Never make a status tappable on its own; make the row or its title the link.

Content

  • Use the seventeen words exactly; do not invent synonyms (Done, Error, Working).
  • A custom label replaces the word only when it is more specific and keeps the tone: Budget reached for Paused, Connected for Succeeded.
  • Pills are short noun phrases or facts in sentence case: No acceptance test, Feature direction.
  • Counts are bare numbers; the label beside them says what is counted.
