Toast

Toasts tell an Owner that something happened elsewhere (a PR merged, a stage started, a direction blocked) without taking them away from what they are doing.

WCAG 2.2 AAStatus: stablerole="status" / role="alert" regions

Overview

Use a toast for news from the live event stream about something the person is not looking at. Toasts are brief, never block, and never hold the only copy of information: every event is also in the dashboard's event stream and the project's own pages.

  • Use an alert strip for a condition that lasts (connection lost, all workers stopped), because a toast would leave while the condition stays.
  • Use an inline callout for the result of something the person did on this page (Defaults saved, Stage failed).
  • Use a Dialog when the person must decide before continuing.

Anatomy

  1. IconTone icon, 16px, aria-hidden; the title carries the meaning.
  2. Title.toast__title: what happened, with the project name.
  3. Text.toast__text: the detail or the consequence, one line.
  4. Actions (optional).toast__action: up to two text actions; links when they navigate.
  5. Close.toast__close: 28px button, aria-label="Dismiss: …".

Variants

Four tones. The tone changes the icon colour (and the ring for danger), never the surface, so a stack stays calm.

  • Paused: while the pointer is over a toast or focus is inside it, its timer stops (2.2.1); it restarts with the full remaining time when both leave.
  • Dismissed: the close button or Esc inside the toast removes it at once; the event stays in the event stream.
  • Overflow: a fourth toast removes the oldest visible one into the +n more in the event stream count.

Responsive behaviour

  • Base (360px): the region is fixed 16px from the left, right and bottom (plus env(safe-area-inset-bottom)), so toasts are full width on phones.
  • From sm (36rem): the region is 24rem wide at the bottom right; the left edge is free.
  • Toast text wraps; actions stay on one row and wrap only if the screen is narrower than 320px.
  • The region sits above sheets and drawers (--z-toast) but below tooltips; on phones it moves up above a bottom sheet's sticky footer.

Theming

Toasts are --color-bg-surface-raised with --shadow-3 and a hairline ring, so they float in both themes; dark elevation comes from the lighter raised surface more than the shadow. Tone modifiers set two component tokens, --toast-ring and --toast-icon.

/* A quieter warning toast for a dense monitoring wall */
.wall .toast--warn { --toast-icon: var(--color-fg-muted); }

Accessibility

Role and pattern

Two persistent live regions exist from page load (a live region added at the same time as its content is not announced): <div class="toast-region" role="status" aria-live="polite"> for info, success and warning, and a separate role="alert" region for danger. Toasts themselves carry no role. This follows the APG alert pattern and 4.1.3 Status messages.

Keyboard

KeyAction
TabReaches toast actions and close buttons in DOM order; the regions sit at the end of <body>, so they never interrupt the page's tab order.
Enter, SpaceActivates the focused action or close button.
EscWith focus inside a toast: dismisses it and moves focus to the next toast, or back to #main if it was the last.

Focus

A toast never takes focus when it appears. Hovering or focusing it pauses its timer. Dismissing moves focus to the next toast or to #main, never to <body>.

Labelling

The title and text are the announcement, so they must make sense alone: Parcel Post is blocked. Requirements failed after 3 retries. Close buttons name the toast: Dismiss: Parcel Post is blocked. Icons are aria-hidden.

Motion

Enter: rise and fade over --duration-slow; leave: fade and drop over --duration-base. Under reduced motion both durations are effectively zero, so toasts appear and disappear in place; the time-left line still shrinks because it conveys time, not decoration.

Touch

The close button is 28px (--control-height-xs) and actions are 24px tall text targets with 12px between them; on phones a toast can also be swiped sideways to dismiss.

Content

  • Title: what happened, project first, past tense or a state: Ledgerline #27 merged, Parcel Post is blocked, Kiln Booking at 80% of budget.
  • Text: the detail or consequence, with numbers: $200.00 of $250.00. It pauses at $250.00.
  • Reassure when something failed: Other projects keep running.
  • Actions are verbs and at most two: Open log, Retry stage. No OK; the close button covers that.
  • No exclamation marks, no Success!.
