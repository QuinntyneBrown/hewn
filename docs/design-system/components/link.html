Link

Links take people somewhere: another page in Mission Control, a pull request or commit on GitHub, a design in Magic Patterns.

Overview

Use a link when activating it only navigates. If it changes something (retry a stage, raise a budget, open a dialog that acts) it is a Button, even when it looks like text (.btn--link). Links that look like buttons (a.btn) are fine for navigation calls to action such as New direction.

  • Inline (plain <a>): inside a sentence; --color-fg-link, always underlined.
  • Quiet (.quiet-link): secondary references in dense rows and logs; subtle until hovered, then underlined.
  • Quiet mono (.quiet-link.mono): commit SHAs and PR numbers, with a leading icon.
  • External (.link-external): leaves Mission Control (GitHub, Magic Patterns). Adds ↗ and opens in a new tab, so the live dashboard keeps streaming.
  • Row title (.row__title): the name that opens a row's object; see row list.

Anatomy

  1. Link text--color-fg-link; says where it goes.
  2. Underline--border-width-hairline thick, offset 0.15em; always on for inline links.
  3. External mark.link-external::after adds ↗; a visually hidden (opens in a new tab) says the same to screen readers.

Links take the size of the text they sit in; they have no sizes of their own. Standalone links in rows follow the row's type role.

  • Visited is deliberately the same as default: almost every link in Mission Control leads to a live page that changes, so “already seen” is not useful and would add a second link colour.
  • Active has no separate style; navigation starts on release.
  • Current (aria-current="page") is styled by the navigation components that use it: sidebar, tabs, breadcrumb.
  • There is no disabled link. If the destination is unavailable, render the text without href and say why.

Responsive behaviour

  • Inline links wrap with their sentence at every breakpoint; long URLs and repository paths break with overflow-wrap: anywhere inside their container rather than widening the page.
  • Quiet mono links never wrap (SHAs and PR numbers are short); in rows below lg they move under the title with the rest of the row's metadata.
  • Standalone links in rows need a 24px target: quiet links in the Decisions list are only as tall as their caption text, so a min-height: --target-min is logged for components.css.
  • On phones, external links still open a new tab; the browser's back button returns to the dashboard.

Theming

Links read --color-fg-link and --color-fg-link-hover; quiet links read --color-fg-subtle and --color-fg-default. In dark the link colour is the light accent (--palette-blue-400 via the semantic token), which keeps 4.5:1 on every surface. Underlines use currentColor, so they re-theme automatically and survive forced colours.

Accessibility

Role and pattern

Native <a href>, per the APG link pattern. Never a <span> or <button> with a click handler for navigation, and never href="#" for an action.

Keyboard

KeyAction
Tab / Shift + TabMoves to and from the link.
EnterFollows the link. Space scrolls the page; it does not activate links.
Ctrl + Enter / ⌘ + EnterOpens in a new tab (browser behaviour; never blocked).

Focus

The shared ring (2px --color-focus-ring, 2px offset), drawn around the text box of the link. Inline links that wrap show the ring on each line fragment.

Labelling

The link text is the name and must make sense alone (2.4.4): View pull request #27 on GitHub, not here. Short references get a visually hidden prefix (Commit, Pull request). Icon-only links (.file__open) carry an aria-label that names the target: Open docs/brief.md on GitHub at e8812fa. External links include (opens in a new tab) in their name.

Motion

No transitions; colour and underline change instantly on hover.

Touch

Inline links in sentences are exempt from the 24px target rule; standalone links (rows, decision links, toolbars) are at least 24px tall with 8px between them. Nothing about a link is hover-only: the underline is always present on inline links.

Content

  • Link text names the destination: Open log, View all, Install the app on that repository.
  • Never click here, here, more or a bare URL.
  • External links name the place they go: … on GitHub, Open in Magic Patterns.
  • Identifiers keep their exact form in monospace: a41c9e2, #14, hewn-builds/ledgerline.
