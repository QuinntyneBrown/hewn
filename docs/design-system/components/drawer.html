Drawer

The drawer is the app’s navigation below 992px: the sidebar, slid in from the start edge over a backdrop, opened by the top bar’s menu button.

WCAG 2.2 AAStatus: stableAPG Dialog (Modal)Below lg only

Overview

Use the drawer for the primary navigation on phones and tablets, where the Sidebar nav does not fit. It holds exactly the sidebar: the New direction button, the primary links, active directions, connection state and the signed-in user. Do not use it for forms or confirmations: those are dialogs.

  • Start (default): slides in from the left edge; the navigation drawer.
  • End (.drawer--end): slides in from the right edge; available for a future detail panel, unused by the mocks.

Anatomy

  1. Close button.drawer__close: 44px ghost icon button, top end; first focus.
  2. BrandThe wordmark, linking to the dashboard.
  3. NavigationThe sidebar’s CTA, primary links and active directions.
  4. FooterConnection state, worker count and the user.
  5. Panel--layout-drawer-width (18rem), max 85vw, full height, --shadow-4, hairline on the inner edge.

Sizes

One width: --layout-drawer-width (18rem), capped at 85vw so a strip of the page stays visible.

States

Closed, the drawer is not rendered (or hidden). Open, it is modal: the backdrop covers the page, the page is inert, focus starts on Close. The links inside have their own states: hover (shown on Projects) and current (Dashboard, aria-current="page").

Responsive behaviour

  • Base to md: the top bar shows the menu button (44px, .btn--touch); the drawer is 18rem or 85vw, whichever is smaller.
  • md to lg: same drawer; the page behind keeps its layout.
  • From --layout-breakpoint-lg (992px): the sidebar is permanently visible, the menu button is hidden, and an open drawer closes.

Theming

The drawer reads --drawer-width (default --layout-drawer-width), --color-bg-surface, --color-border-default and --shadow-4; it sits on --z-modal above the --color-bg-backdrop scrim on --z-overlay. The sidebar inside keeps its own --nav-* tokens.

In dark the panel is the surface tone and the backdrop deepens, so the drawer separates from the page without a visible shadow.

Accessibility

Role and pattern

APG Dialog (Modal): role="dialog", aria-modal="true", aria-label="Menu"; the page behind is inert. The menu button in the top bar has aria-expanded and aria-controls pointing at the drawer. Inside, the links are a <nav aria-label="Primary, menu">, distinct from the desktop sidebar’s Primary.

Keyboard

KeyAction
Enter / SpaceOn the menu button: opens the drawer, focus moves to Close.
Tab / Shift + TabCycles through the drawer only.
EscCloses the drawer; focus returns to the menu button.
EnterOn a link: navigates and closes the drawer.

Focus

Focus starts on Close, is trapped while open and returns to the menu button on close. Links show the shared ring.

Labelling

The drawer is named Menu; Close is named Close menu. Status icons in the project list are paired with visually hidden status words (Parcel Post, Blocked, 24%).

Motion

Slides in from its edge (slide-in-start, --duration-slow, --ease-enter); reduced motion zeroes it.

Touch

Links and project rows are 44px tall below lg; Close is 44px. Tapping the backdrop closes the drawer.
