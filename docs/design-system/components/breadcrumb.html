Breadcrumb

A one-line trail above a project page's title that says where the page sits: Projects, then the project, then any parent, then the page.

WCAG 2.2 AAStatus: stable<nav aria-label="Breadcrumb">

Overview

Breadcrumbs appear only where the hierarchy is deeper than the sidebar shows: inside a project. The Project header starts with Projects › Ledgerline on every project section; the increment page shows Projects › Ledgerline › Backlog › Increment 7. Top-level pages (Dashboard, Projects, Workers, Audit, Settings) have no breadcrumb: the sidebar's current item already says where you are.

The trail is navigation, not a history: it lists ancestors, never the pages you came through. The last item is the current page and is not a link.

Anatomy

  1. Ancestor linkPlain <a> inheriting the subtle caption colour; underlines on hover.
  2. SeparatorA 12px chevron-right in its own <li aria-hidden="true">; never typed as > or /.
  3. ParentAs many levels as the route has; Hewn's deepest is four.
  4. Current page<li aria-current="page">, muted (one step stronger than the links), not a link.

There is no collapsed variant with an ellipsis menu: four short levels fit at 360px on two lines at most. If a future route goes deeper, collapse the middle levels into a Menu rather than truncating names.

Sizes

Breadcrumbs have one size: caption type (12px) with 12px separators.

Pointer and focus states are forced with data-state; the current item uses the real aria-current="page".

Responsive behaviour

  • Below --layout-breakpoint-sm (576px): the trail wraps (flex-wrap) onto a second line rather than truncating; at 360px Projects › Ledgerline › Backlog › Increment 7 fits on one line, and long project names wrap.
  • sm to lg (576–992px): one line.
  • From lg (992px): unchanged; it aligns with the page padding (--space-8) because it sits inside the project header or the page's .pad.
  • Link targets are 16px tall; see Touch for why that is acceptable.

Theming

The breadcrumb uses --color-fg-subtle for links and separators, --color-fg-muted for the current page and --color-fg-default on hover. In dark the order is the same; subtle is lightened enough to keep 4.5:1 on the dark surface. Override those semantic tokens in a scope to re-skin it; the component has no tokens of its own.

Accessibility

Role and pattern

The APG Breadcrumb pattern: a <nav aria-label="Breadcrumb"> containing an ordered list; the current page has aria-current="page". Separators are aria-hidden so they are not read and the list length counts only real levels.

Keyboard

KeyAction
TabMoves through the ancestor links; the current item is skipped.
EnterFollows the link.

Focus

The shared ring on :focus-visible around the link text. Because the links are small, the ring's 2px offset keeps it clear of the separators.

Labelling

The landmark is named Breadcrumb, so a screen reader lists it as Breadcrumb navigation. Link text is the page name exactly as its <h1> says it.

Motion

No motion: link colour changes on hover are instant.

Touch

Links are text-height (about 16px), below 24px, so they rely on the WCAG 2.5.8 inline exception and on spacing: each link has at least 24px of clear target space thanks to the separators and gaps. Every ancestor is also reachable through larger targets: the sidebar's Projects link and the project tabs.

Content

  • Use the destination page's own title: Projects, Ledgerline, Backlog, Increment 7.
  • Do not add Home or Dashboard at the start; the trail starts at the top-level section.
  • The last item matches the <h1> below it.
  • No trailing separator after the current page.
