Description list

Description lists pair a label with a value: a stage's skill, output, duration and worker; the sections of a pull request body. The label is quiet, the value is what people read.

WCAG 2.2 AAStatus: stableNative <dl>

Overview

Use a description list for facts about one object, where each fact has a name. Use a Table when the same facts repeat for many objects, and a List when items have no labels.

  • Vertical (.kv): label above value, for long values such as the PR body's What, Tests and Notes.
  • Horizontal (.kv--row): an 8rem label column beside the value, for short facts on a detail page.
  • Inline meta (.meta): label and value pairs that wrap as a line under a heading: a stage's Skill, Output, Duration, Worker.

Anatomy

  1. Term<dt>: caption (kv) or body-sm (meta) in --color-fg-subtle.
  2. Value<dd>: --color-fg-muted; mono for skills, paths and hosts (.mono).
  3. GroupEach pair is wrapped in a <div> (valid inside <dl>) so it lays out as a unit.

Responsive behaviour

  • .kv is one column at every width.
  • .kv--row keeps the 8rem label column down to 360px; values wrap. If labels are longer than 8rem, use .kv.
  • .meta wraps pairs onto new lines (gap --space-1 by --space-6); each value truncates rather than pushing the line wider than the screen.

Theming

Terms read --color-fg-subtle and values --color-fg-muted; both pass 4.5:1 on canvas and surface in both themes. Inline code inside values uses the code type at 0.92em. No component tokens: the list is pure type and colour.

Accessibility

Role and pattern

Native <dl>, <dt>, <dd> with <div> groups; screen readers announce term and definition pairs. No widget pattern applies (see the APG note on structural roles: term, definition).

Keyboard

KeyAction
TabReaches links inside values (a commit, an ADR); the list itself is not focusable.

Focus

Only links inside values take focus, with the shared ring.

Labelling

Every value has a visible term. A term may be visually hidden only when the value explains itself (the PR body's attribution line, Built by Hewn · direction 7 Nov · run-0412).

Motion

None. Values that change live (Duration while a stage runs) update in place without animation and are not live regions.

Touch

Not interactive. Links in values follow the link rules (the text is the target).

Content

  • Terms are short nouns in sentence case: Skill, Output, Duration, Worker, Design and decisions.
  • Values are fragments or one sentence, ending with a full stop only when they are sentences.
  • Durations as h:mm:ss or m:ss (3:12:48, 22:16); hosts with their location (quinn-mbp.local · Local).
  • Missing values say why or use an em dash.
