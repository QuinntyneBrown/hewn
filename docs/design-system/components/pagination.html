Pagination

Pagination moves through a long, ordered list a page at a time. It is in the core set but no mock uses it yet; the audit log is the first list that needs it.

Overview

No Hewn mock paginates today. Every list in the mocks is short: 7 projects, 4 workers, 12 increments, 5 decisions, and the pages/audit/default (10 audit entries). The audit log is the exception waiting to happen: L2-044 records every sign-in, direction, pause, resume, cancel, stop, token and merge, newest first, and entries are never deleted, so it grows without bound. This page specifies the component that list will use, built from the CSS already in components.css.

  • Use pagination for append-only records people search back through: the audit log, a project's run history.
  • Do not paginate live streams (the worker log, the event feed); they follow the newest line and offer Jump to latest.
  • Do not paginate short working lists (projects, workers, backlog); filter them instead.
  • Pagination sits below the table, after the last row, and keeps the filters above in the Page header.

Anatomy

  1. RangeShowing 1–10 of 248 entries: body-small, muted, tabular.
  2. Previous.pagination__page link; on page 1 it is aria-disabled="true" with no href.
  3. Current pagearia-current="page": raised background, strong edge, medium weight.
  4. EllipsisAn aria-hidden … between non-adjacent pages.
  5. Next and lastThe last page (25) is always shown, so the length is visible.

  • Disabled Previous on page 1 and Next on the last page keep their place (so the row does not jump) and use aria-disabled="true" without href, so they are announced but not followed.
  • Active has no separate style; the page load is the feedback.
  • Loading the next page keeps the bar and replaces the rows with skeleton rows; the range text updates when the rows arrive.

Responsive behaviour

  • Below --layout-breakpoint-sm (576px): the numbered pages are hidden and replaced by Page 1 of 25 between Previous and Next (.sm-only / .sm-hide); the range text wraps above.
  • From sm (576px): numbered pages show; the range sits left and the controls right (justify-content: space-between), wrapping if the table is narrow.
  • Below lg targets are 44 × 44px (--target-comfortable); from lg (992px) they are 32px (--control-height-sm).
  • xl (1200px): unchanged; at most seven page items are ever shown.

Theming

Pagination reads --color-fg-muted for labels, --color-bg-subtle on hover, --color-bg-surface-raised and --color-border-strong for the current page and --color-fg-disabled for disabled ends. The current page's edge uses the strong border so it passes 3:1 as a boundary in both themes; in dark the raised fill steps up from the canvas.

Accessibility

Role and pattern

No APG widget applies; pagination is a set of links in a <nav> landmark (APG landmark regions) named for the list it pages, with aria-current="page" on the current page. Links, not buttons: each page has a URL (/audit?page=12) that can be shared and survives reload.

Keyboard

KeyAction
TabPrevious, each page, Next, in order; disabled ends are skipped (no href).
EnterLoads that page.

Focus

The shared ring on :focus-visible. After a page loads, focus moves to the table caption (Audit log, newest first, page 12 of 25) so keyboard and screen-reader users start at the new rows, not at the bottom of the page.

Labelling

Name the landmark for the list: Pagination, audit log. Page links read Page 2 (the word Page is visually hidden). The range text is plain text; it is not a live region, because focus moving to the caption already announces the change.

Motion

No motion beyond the hover background change.

Touch

44 × 44px targets below lg with --space-1 gaps; numbered pages are hidden on phones so the remaining two targets are large and far apart.

Content

  • Range: Showing 1–10 of 248 entries with an en dash and the list's own noun (entries, runs).
  • Controls: Previous and Next, in words. No «, » or bare arrows.
  • Position on phones: Page 12 of 25.
  • Numbers are tabular so the bar does not shift between pages.
