Code block

Code blocks hold text people copy or read exactly: a worker token shown once, the docker command that starts a worker, a failing test's output. Keys and hidden secrets use the same mono family.

WCAG 2.2 AAStatus: stable<code> / <pre>

Overview

Use a codebox for one value to copy (a token, an ID), a pre block for multi-line commands and output, inline code for file names and identifiers in prose, .kbd for keys, and .secret for a value that exists but is never shown. Streaming output belongs in the log viewer.

  • Codebox (.codebox): one line, truncated with an ellipsis, a copy button at the end.
  • Pre (.pre): preformatted, scrolls horizontally, never wraps (commands must paste exactly).
  • Inline code: <code> at 0.92em inside text.
  • Key (.kbd): a keycap with a bottom edge.
  • Secret (.secret): eight dots that stand for a value Hewn stores encrypted and will not show again.

Anatomy

  1. Container--color-bg-surface-sunken, hairline ring, --radius-md, padding --space-2 / --space-3.
  2. ValueMono at --font-size-sm, one line, ellipsis when long; selecting it selects the whole value.
  3. Copy buttonSmall ghost icon button labelled Copy token; becomes Copied with a check.

One size each: codebox and pre use code type (14px in the codebox, 12px code text in pre with loose line height); kbd and secret follow the code token.

Responsive behaviour

  • Codebox: the value truncates to the width; the copy button never wraps below it.
  • Pre: never wraps; scrolls horizontally inside its own box at every width, so the page does not scroll at 360px.
  • In the worker-token bottom sheet (below sm) both blocks take the full sheet width.

Theming

Both blocks read --color-bg-surface-sunken and --color-border-default; codebox text is --color-fg-default, pre text --color-fg-muted. In light the sunken surface equals the canvas, so the ring is what separates it inside a dialog; in dark it is the deepest slate, below the dialog's raised surface.

Accessibility

Role and pattern

<code> and <pre> are plain text. The copy control follows the APG button pattern. A pre that can overflow is a named scroll region: tabindex="0" role="region" aria-label.

Keyboard

KeyAction
TabMoves to the copy button, then into the pre block.
Enter, SpaceCopies.
← →With the pre focused: scrolls long lines.
Ctrl + AWith the pre focused, selects the page; select inside the block with the pointer or Shift + arrows.

Focus

The shared ring on the copy button and the pre region. Focus stays on the copy button after copying.

Labelling

Copy buttons say what they copy (Copy token, Copy command). The pre region's label says what the text is. Secrets replace the dots for screen readers with Secret set, hidden; the dots are aria-hidden.

Motion

None beyond the button's colour transition; the copied state is a swap, not an animation.

Touch

The copy button is 32px; on a phone in the bottom sheet it is the main action next to Done, so keep 8px around it. Long-press on the value selects it as a fallback.

Content

  • Commands are exactly what runs, with line continuations, and no prompt character ($) so they paste cleanly.
  • Say once, next to a one-time value, that it will not be shown again: Copy it now. Hewn stores only a hash and can’t show it again.
  • Keys are named as printed on the keyboard: Esc, Ctrl, t.
  • Put file names, environment variables and IDs in inline code: HEWN_WORKER_TOKEN, docs/specs/.
