Spinner

A spinner says the app is working on something right here and does not know how long it will take. It always comes with words.

WCAG 2.2 AAStatus: stable

Overview

Use a spinner for a short, unmeasured wait tied to one place: a button that is submitting, a connection being re-established, a stage that is running. The loader icon turns; the words say what is happening.

  • Loading a page or a region: use a Skeleton shaped like the content, not a spinner in the middle of nothing.
  • Measurable work: use a Progress bar.
  • A running stage or worker: the Running status uses the same spinning loader with its word.

Anatomy

  1. IconThe loader icon in --color-fg-accent, turning on --duration-spin; aria-hidden.
  2. LabelWhat is happening, progressive verb with an ellipsis, --color-fg-muted.

Button

Reduced motion sets --duration-spin to 0s, so the loader stands still; the label keeps saying it is working. When the work finishes the spinner is replaced by the result (a message, the loaded content, the button's normal label), never left turning.

Responsive behaviour

A spinner is inline and sized with its text; it behaves the same at every breakpoint.

Theming

The icon reads --color-fg-accent and the label --color-fg-muted; inside a button or strip the icon inherits the text colour instead, so it matches the variant in both themes.

Accessibility

Role and pattern

The icon is aria-hidden; the label is the information. Put the spinner's label in a role="status" container that exists before the label is inserted, so Loading increment 7… is announced once (4.1.3 Status messages). In buttons, aria-busy="true" and aria-disabled="true" carry the state, as on the Button page.

Keyboard

KeyAction
NoneSpinners are not focusable. A busy button keeps focus and ignores Enter and Space until it finishes.

Focus

Never takes or moves focus. When a busy button finishes, focus stays on it (or moves with the dialog that closes).

Labelling

Always a visible label; never an icon alone. Icon-only spots (a running status in a dense row) carry the word in the row: Running.

Motion

One full turn per --duration-spin (2.4s), linear. It is a continuous loop, so under reduced motion it stops (0s); no flashing, never faster than once per second.

Touch

Not a target.

Content

  • Progressive verb plus object and an ellipsis character: Loading increment 7…, Waiting for GitHub…, Reconnecting….
  • If the wait has a known next step, say it: Reconnecting… next attempt in 10 s.
  • Never Please wait or Loading… with no object.
