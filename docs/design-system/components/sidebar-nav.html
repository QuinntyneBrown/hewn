Sidebar navigation

The app sidebar: brand, the one primary action, five destinations, the active directions with live status, and a footer with the connection, the worker count, Stop all workers and the signed-in user.

Overview

The sidebar is the product's primary navigation and its at-a-glance health panel. It is always visible from lg in .shell__sidebar (sticky, full height, scrolls on its own) and rendered unchanged inside the Drawer below lg, opened from the Top bar.

  • Brand: the wordmark, linking to the Dashboard.
  • New direction: the one primary button (Owners only). It is the product's main verb, so it sits above the navigation, not in a page header.
  • Primary navigation: Dashboard, Projects, Workers, Audit (Owners only), Settings. Icon plus label; the current page is aria-current="page".
  • Active directions: every Running, Paused or Blocked project, with its status icon, name and percent complete (Ledgerline 62%, Tidewater 18%, Parcel Post 24%, Kiln Booking 81%). Idle, Complete and Cancelled projects live on the Projects page.
  • Footer: connection (Live / Reconnecting… / Offline), 3 of 4 workers, Stop all workers (Owners) and the user's initials, name and role.

There are no collapsible groups and no icon-only collapsed mode: five destinations and a handful of projects fit at 15rem, and labels are faster to scan than icons.

Anatomy

  1. Brand.sidebar__brand: 64px tall, --space-5 inline padding, the wordmark link.
  2. Primary action.sidebar__cta: a block primary button, Owners only.
  3. Navigation<nav class="sidebar__nav" aria-label="Primary"> of .nav-links: 20px icon, label, optional count badge.
  4. Section label.sidebar__section, overline type, labels the list with aria-labelledby.
  5. Active directions.sidebar__projects of .side-project: status icon, truncating name, hidden status word, tabular percent.
  6. Footer.sidebar__foot: .conn, Stop all workers, .user with avatar, name and role, and a ghost icon button, Sign out, that ends the session and opens sign-in's signed-out state.

Variants

The role decides what is shown. Owners get the primary action, Audit and Stop all workers; Viewers get neither the actions nor Audit, rather than disabled copies of them.

  • Current: raised background, default text colour, medium weight, accent icon. It is the only place accent appears in the navigation.
  • Active has no separate style: navigation is instant and the new current state is the feedback.
  • Count badge (.nav-link__badge) is reserved for things that need the Owner: blocked projects. It carries an aria-label with the meaning (1 blocked), not just the number.
  • Active directions show status as icon plus a visually hidden word (, Running,), never colour alone. They update live; their list is not a live region, because the toast and dashboard already announce changes.

Responsive behaviour

  • Below --layout-breakpoint-lg (992px), at every smaller size (xs, sm 576px, md 768px): .shell__sidebar is display: none; the sidebar is reached through the top bar's menu button and rendered in the drawer. Rows are 44px (--target-comfortable) for touch.
  • From lg: the sidebar is visible, 15rem wide, sticky at the top with its own scroll (height: 100dvh; overflow-y: auto), so a long project list never pushes the footer off screen. Nav links drop to 40px (--control-height-md) and active directions to 32px (--control-height-sm).
  • xl (1200px) and wider: unchanged. The extra width goes to the page, not the rail.
  • Long project names truncate with an ellipsis; the percent never wraps.

Theming

The sidebar declares its own component tokens so a re-skin does not touch the CSS: --nav-fg, --nav-fg-hover, --nav-bg-hover, --nav-bg-current, --nav-icon-current. They alias --color-fg-muted, --color-fg-default, --color-bg-subtle, --color-bg-surface-raised and --color-fg-accent.

/* A tinted current item for a demo workspace */
.sidebar--demo { --nav-bg-current: var(--color-accent-subtle); }

In dark the sidebar surface sits one step above the canvas and the current item one step above that, so the hierarchy survives without borders. The danger Stop all workers button becomes the dark red tint described on Button.

Accessibility

Role and pattern

A <nav aria-label="Primary"> of plain links inside an <aside>; see the APG landmark regions guidance. It is not an ARIA menu: no role="menu", no arrow-key handling, Tab moves through the links. The current page uses aria-current="page". The active-directions list is a labelled <ul> outside the nav, because it lists objects, not destinations.

Keyboard

KeyAction
Tab / Shift + TabBrand, New direction, the five links, each active direction, Stop all workers, in that order.
EnterFollows a link; on Stop all workers opens the confirmation dialog.
EscIn the drawer: closes it and returns focus to the menu button.

Focus

The shared ring on :focus-visible, drawn outside the 8px-radius row so it is not clipped by the rail (the rail has --space-3 inline padding for it). After navigation focus moves to the new page's <h1>, not back to the sidebar.

Labelling

Navigation: Primary (and Primary, menu in the drawer, so the two landmarks differ if both are ever present). Active directions: labelled by the visible Active directions text via aria-labelledby. Each project link reads Ledgerline, Running, 62%. Icons are aria-hidden; the avatar is decorative because the name sits beside it.

Motion

Background and colour transition over --duration-fast on hover. The reconnecting dot pulses; reduced motion stops it. Running project icons spin through .icon--spin and also stop under reduced motion.

Touch

Every row is 44px below lg, where the sidebar is in the drawer and used with a thumb. From lg (pointer) rows are 40px and 32px, still above the 24px minimum, with 2px gaps.

Content

  • Destinations are single nouns in sentence case: Dashboard, Projects, Workers, Audit, Settings. No verbs, no My.
  • The section label is Active directions: the product calls a running piece of work a direction.
  • Worker count is 3 of 4 workers (connected of registered), tabular.
  • Project names are shown as entered and truncate; the percent is a whole number with %.
  • The footer shows the GitHub login (quinntynebrown) and the role (Owner / Viewer).
