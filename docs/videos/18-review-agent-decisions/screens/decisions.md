**Rationale:** The direction names its audience; a narrower first user keeps the brief testable.

**Answer:** Default, loading, empty and error for every screen.

**Rationale:** Each screen loads data, so every state applies (writing-html-mocks state rules).

**Rationale:** Names carry meaning only once roles are known; the values are what the mocks require.
