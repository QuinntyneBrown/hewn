# Journey prompts

One ready-to-run feature prompt per journey in [`docs/journeys.md`](../journeys.md). Each takes its journey
from requirements and design alignment through test-first implementation, a narrated video with background
music, and a pull request, to the merge. Run them in order (highest value first), or in build order when a
journey depends on another.
